## 数值验收

34 个 CPU 验证脚本全部通过，CI 运行相同脚本集合。其中包括：

- BPE 频次/合并次序/重叠/UTF-8 往返，重复嵌入行梯度。
- 移位标签、有效目标平均、屏蔽位置零梯度。
- 逐头循环与矩阵注意力、因果性、样本隔离、完整前向与反向。
- 双向置换、同步重排遮罩、固定因果遮罩反例、全屏蔽行拒绝。
- RoPE 相位、范数与梯度；随机三层和训练恢复后的完整两层缓存 logits。
- 温度/top-k/top-p、固定 generator、EOS 与零输出预算。
- AdamW 手算、不同大小微批梯度、梯度裁剪、固定批过拟合。
- 完整 checkpoint 恢复后 12 步与连续运行的参数及损失逐项相等。
- SFT 直接损失梯度与提示间接梯度、格式任务拟合；LoRA 初始化、冻结、合并和 adapter 保存加载。
- 在线 softmax、分页所有权、量化尺度/零点/元数据、条件投机拒绝/补偿/bonus、TP 与 PP、TTFT/ITL/TPOT/分位数。
- 稀疏专家与同路由参考、MLA 显式与吸收计算、DPO 与 GRPO 梯度、状态组合、窗口 ring cache、稀疏读取、像素到文本目标。

这些实验验收教学算法与协议，不冒充大型模型训练复现或 GPU 性能实测。
