# MDX 可读性审计与整改

审计日期：2026-10-02。范围：`site/src/content/lessons/` 的全部 68 个 MDX，含 7 个导读页。工作顺序：先逐页审计，汇总问题，再由多个 subagent 按路线分批修改，最后统一验收。

## 写作依据与尺度

参考 [ASD-STE100 官方说明](https://www.asd-ste100.org/about.html) 的受控语言原则。该标准面向英文，包含写作规则和受控词典。本次采用其约八成的清晰表达思路，用于中文教程，不声明符合标准。

- 一句话说明一个主要动作或判断。明确执行者、对象和成立条件。
- 一段处理一个主题。计算步骤、实现差异、测量限制分别说明。
- 同一概念使用同一名称。保留 token、logits、KV cache 等已有术语及 API 原名。
- 保留必要推导、数值、反例和验证边界。简洁不等于删除解释。
- 关系、依赖和状态转换优先用图表达。公式和图后仍说明如何读取。
- 交互说明给出“设置什么 → 做什么 → 检查什么”。复杂练习用原生折叠答案。

现有 MDX 已生成 HTML 网页，并支持 Mermaid、主题化 SVG、React 实验和折叠练习。优先复用这些能力。

## 审计结论（修改前）

| 问题 | 具体证据 | 整改方式 |
| --- | --- | --- |
| 单段承担过多任务 | G4 开篇同时给出矩阵形状、两版实现状态、比较条件和设备限制；S6 重放段同时说明输入复制、padding、副作用和旧块表 | 按计算、操作、边界拆段，补明确主语 |
| 交互说明难以执行 | S5 的 PagedKvLab 后直接进入下一节；S3 用“读取默认三项块”描述状态，却未清楚指出滑块操作 | 交互前给目标，交互后给顺序与预期读数 |
| 正文、图注和实验说明重复 | P3 causal mask 后两段重复默认查询位置与温度范围；多个路线导读重复概念链 | 合并重复说明，保留读图方法与先修链接 |
| 文字连续描述状态变化 | S4 的采样与 KV 计数、S5 写时复制、S8 拒绝后的 KV 保留边界 | 将关键路径画成小型流程图，沿用同一案例 |
| 教学实验与正文口径不一致 | P8 的 `d=n_q d_h` 与其数值案例不符；P9 min-p 主例 0.6 超过实验滑块上限 0.5，重复惩罚范围也不同；A2 静态与实验的缓存布局不同 | 修正错误，明确实验支持范围及不同布局假设 |
| 导读页密度高 | 数学、框架、原理、训练、系统导读以连续段落列出大量章节与先修 | 给可扫描的阅读路径或现有路线图观察任务 |

现有内容的优点需要保留：贯穿的小案例、完整推导、数学成立条件、CPU 断言、原始资料、GPU 实测边界、现有移动端图和交互。上述问题不意味着每页都缺图，也不以组件数量衡量质量。
