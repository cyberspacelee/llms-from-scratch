# 当前课程设计与验收

教材正文只保存在 `site/src/content/lessons/`。主题目录和章节编号来自 frontmatter；目标路线来自 `site/src/lib/curriculum.ts`，先修由每篇 `prerequisites` 声明。新增页面必须通过先修存在性、无环检查与站内链接检查。这里规定教学边界，完整章节清单由各目录 `index.mdx` 与 `CourseMap` 生成。

## 数学与框架

数学 M1–M10 围绕一次训练建立概率、损失、矩阵、梯度与更新。M11 从对称矩阵解释特征方向和稳定步长；M12 从线性映射解释奇异值、截断误差与条件数，作为独立选读接入 LoRA。

框架 F1–F7 围绕轴、存储、求导、模块、有效目标分母、数据状态和编译边界。F4 手算、网页与 Python 使用同一个向量分支损失；F5 全忽略时的局部零梯度不能被误解为允许优化器推进；F6 恢复要保存完整训练事件状态。

验收：用一个改变输入、轴或有效 mask 的变式，核对形状、输出和梯度。概念定义与源码引用不能由同一个错误实现互相证明，保留手算、有限差分或框架算子作为独立参考。

## 原理：从基础块逐项组装

P1–P4 建立 token、下一项目标、注意力与基础 Decoder。基础配置使用 learned positions、pre-LayerNorm、GELU 与独立输出权重，来自同一个 `Transformer`。

P5–P7 分开顺序问题、加法 sin/cos 与旋转 RoPE。P8 只比较归一化；P9 只改变 KV 头数；P10 只改变前馈分支。每章只引入一个结构变化，先在同一小例子中计算再讨论参数或状态账。

P11–P12 解释生成和缓存；P13 从统一包组装 RMSNorm、GQA、RoPE、SwiGLU 的完整模型。旧二维完整 trace 留作终章选读，不在首次学习归一化时同时引入整个现代模型。

P14 的经典 encoder/cross-attention 是独立分支：区分 source/query 两个长度轴、双向/因果/矩形三种 mask，并用可手算矩形例子暴露错误 `tril`。

验收：完整与 chunk 输出、因果扰动、padding、不独立的模型宽度与头宽、绑定参数梯度、矩形缓存位置。引用的是实际模型函数，而非另一套长期维护的通用 Decoder。

## 训练与后训练

训练 T1–T4 分别建立数据目标、优化、真实文本循环、固定协议评估；T5 单独验证 checkpoint 的精确恢复。T6 的规模拟合、T7 的原始记录处理与 T8 的分布式更新按实际任务接入。

真实预训练的唯一案例是八篇文档，tokenizer 只拟合训练文本，窗口、有效目标与数据指纹明确。四 ID 循环只在恢复章作为可控协议实验，不把其损失当作自然文本结果。

后训练 H1–H5 分开 SFT、LoRA、分布蒸馏、DPO 和 RLVR。真实模型实验共用统一 `Transformer`；手算核对保留各损失自身的梯度。教师与参考模型冻结，回复 mask、EOS 和归约方式明确。

验收：不等长微批使用有效目标加权；全局空目标跳过全部优化事件；LoRA 冻结与 merge 输出一致；DPO 回复概率只累加回复目标；蒸馏在有效行计算 KL；RL 分开训练题与未见题，奖励提升不等于泛化推理。

## GPU 与服务系统

GPU 四篇主线讲输出负责者、地址与同步、分块设计、测量。三维索引、归约、Triton softmax、模型 profiling 分成按需实践。主线测量沿真实 tiled GEMM 16/32 候选，在相同输入、精度、预热和 CUDA event 边界比较；没有硬件时只报告 CPU 数值检查和源码核对。

系统 S1–S3 分开容量、设备下界与 attention IO；S4–S6 分开调度、分页地址与执行。S7–S10 的量化、推测、多卡和服务评估必须同时交代质量、负载和代价。混合状态的共同恢复边界与滑窗 ring 存储为 S11/S12 选读，区分模型公式和运行期状态所有权。

验收：Graph padding 用无效 slot 与零 context 长度；待处理 ID 不冒充已写入 KV；ring 以绝对 tag 判身份；递归状态不能靠缩短长度回滚；拒绝草稿和共享页释放核对提交边界。

## 结构研究选读

进阶七篇按 FFN、缓存表示、可见集合、递归状态、混合层、稀疏读取和视觉输入选择。五个新研究入口分别讨论未来标签、旧块摘要、残差通道、条件记忆和跨层 K/V。

研究函数是否接入标准 Transformer，要在文章中明确。摘要与原始 dense attention、独立预测头与真值条件串联、双随机混合与整个网络稳定性都必须区分定义与额外假设。公开模型配置和性能只引用核对过的原始资料。

## 逐篇交付

每篇先确认一个完成目标、必要先修与贯穿例子，再检查定义、图、源码摘录和练习是否使用同一对象。独立复审者阅读实际页面和代码，完成至少一个变式，记录无法从正文定位答案的断点；修正后重新核对。

完整 Python 文件放折叠区，正文只展示相关函数或命名 region。SVG、矩阵与图注使用共享组件，移动端文字不缩到不可读，滚动发生在图表自身。

最后执行 CPU 示例、Python 回归、TS 实验检查、Python/TS 数值桥接、站点构建与链接检查；浏览器必须实际触发 `client:visible` hydration，再检查交互、字号、明暗主题和页面横向溢出。
