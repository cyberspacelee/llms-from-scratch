训练一个语言模型，归根到底是四件事：把文本和模型写成张量运算；定义一个衡量“预测得有多好”的损失；求出损失对每个参数的梯度并沿梯度更新；让这一切在有限精度的硬件上稳定地算出来。本书后面的每一章——从注意力到 MoE，从混合精度到 FlashAttention，从 LoRA 到 GRPO——都建立在这四件事之上。第一部分把它们需要的数学一次讲清楚。

这一部分写给有编程基础、但数学可能已经生疏的工程师。我们不假设你记得微积分或线性代数的细节，所有概念都从定义出发；但我们也不满足于“会调用 API”，每个结论都给出完整推导，并落到能运行、被测试的 PyTorch/NumPy 代码上。读完这一部分，你应该能手推一个 Transformer 中任何算子的反向公式，能写出一个可以训练网络的自动微分引擎，能解释交叉熵、困惑度和 bits-per-byte 的含义，能说清楚 BF16 训练为什么比 FP16 省心，也能看懂 LoRA、MLA 和 Muon 论文里的矩阵记号。

## 这一部分解决什么问题

**怎样描述计算？**[向量、矩阵与张量](/math/vectors-matrices/)把一批数据写成张量、把一层网络写成矩阵乘法加非线性。矩阵乘法的四种看法（点积、列组合、外积和、线性变换）会在后面反复出现：点积是注意力分数，外积和是权重梯度与低秩分解，线性变换是每一层对 token 做的事。

**怎样求梯度？**这是第一部分的主线，占了四章。[导数、偏导数与梯度](/math/derivatives/)建立“导数是局部线性近似”的直觉，证明梯度是最速上升方向，并写出第一个梯度下降。[链式法则与计算图](/math/chain-rule/)把复合函数画成图，说明为什么深度学习只用反向模式。[反向传播：从标量到矩阵](/math/backprop/)为线性层、激活函数、softmax 交叉熵和 LayerNorm/RMSNorm 推导反向公式。[从零实现自动微分](/math/autodiff/)把这些规则自动化，先写一个标量引擎训练小网络，再推广到张量并与 PyTorch 逐项比对。

**损失从哪里来？**[概率、最大似然与交叉熵](/math/probability/)把语言模型精确地定义为一组条件分布，证明最大似然等价于最小化交叉熵，并解释困惑度、bits-per-byte 和 softmax 温度。

**机器上怎样可靠地算？**[浮点数与数值稳定性](/math/numerics/)拆开 FP32、BF16、FP16、FP8 的位布局，用实验展示累加误差，推导 log-sum-exp 与方差保持初始化。[特征分解、SVD 与低秩近似](/math/linear-algebra-advanced/)给出谱范数、条件数和 Eckart–Young 定理，为 LoRA、MLA 和 Muon 做铺垫。

## 与前后部分的关系

这是全书的第一部分，没有前置要求，只需要会写 Python、记得高中代数。第二部分 [PyTorch 与资源核算](/pytorch/)会直接使用这里的结论：PyTorch 的 autograd 就是[从零实现自动微分](/math/autodiff/)里那个引擎的工业版本；资源核算中“训练 FLOPs ≈ 6 × 参数量 × token 数”来自矩阵乘法的 $2mnk$ 与反向模式的代价分析；第一个神经语言模型的损失就是交叉熵。第三部分实现注意力时会用到点积、softmax 的稳定计算和 einsum；第五部分的混合精度与优化器分别建立在[浮点数](/math/numerics/)和[条件数](/math/linear-algebra-advanced/)之上；第七部分的 LoRA 与第四部分的 MLA 直接使用 Eckart–Young 定理。

## 阅读与动手建议

每章都遵循同样的节奏：直觉 → 推导 → 手算小例子 → PyTorch 实现 → 测试验证。建议读到手算例子时停下来自己算一遍，再对照正文；读到代码时在本地运行对应的测试，并试着改动参数观察结果。所有代码在仓库的 `src/llms_from_scratch/math/` 下，测试在 `tests/math/` 下：

```sh
uv sync --group dev
uv run pytest tests/math          # 全部测试在 CPU 上数秒内完成
```

如果你已经熟悉微积分与线性代数，可以快速浏览第一、二章，重点读[反向传播](/math/backprop/)中 softmax 交叉熵和 LayerNorm 的推导、[自动微分](/math/autodiff/)中广播的反向，以及[浮点数](/math/numerics/)中的累加实验——这些是工程实践中最常出错的地方。每章末尾的练习都附有答案，答案给出了推理过程而不仅是结论。
