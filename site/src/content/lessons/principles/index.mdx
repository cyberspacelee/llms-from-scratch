数学路线已经训练过分类器：输入一个向量，输出各类别的分数，再用损失更新参数。语言模型面对的是一段文本。它要根据已有内容预测下一个 **token**（文本切分后的单位）；生成一段话，则要把这次预测反复接到新的输入后面。本路线沿着这一个任务，先建出能训练的模型，再弄清顺序、现代结构与逐步生成。

## 主线：从文本到下一 token

<ChapterList track="principles" />

[P1 文本、token 与 embedding](/principles/tokenization/) 把字符串切分、编号，再通过可训练的 embedding 查表变成向量。[P2 下一 token 预测](/principles/language-modeling/) 用 `[BOS,A,B,EOS]` 说明标签为什么要错开一位，以及每个位置的预测如何汇成一次损失。到这里，问题已经明确，但最小的 bigram 模型只能根据当前 token 查表，不能利用更早的上下文。

[P3 注意力与多头](/principles/attention/) 解决“当前的位置怎样读取已有历史”，同时用 causal mask 排除未来位置。[P4 从注意力到完整 Decoder](/principles/decoder/) 将 embedding、位置、注意力、前馈网络和输出层接起来，沿同一段输入算到词表 **logits**（softmax 前的分数）、损失和梯度。这是第一个可以训练的完整模型；它故意采用容易手算的尺寸和学习式位置表。

## 顺序与生成：模型怎样用于真实文本

[P5 注意力从哪里得到顺序](/principles/attention-order/) 区分两件常混淆的事：不带位置信息的双向注意力如何随输入重排，以及固定的 causal mask 如何改变可见历史。[P6 多频率 sin/cos 位置编码](/principles/sinusoidal/) 从二维旋转推到不同频率的位置向量；[P7 相对位置与 RoPE](/principles/rope/) 再把旋转放到查询和键上，使位置对分数的显式影响取决于相对位移。P6 的矩阵指数和 P7 的复数写法都放在选读部分，不妨碍实数主线。

[P8 现代 Decoder 的结构选择](/principles/modern-decoder/) 在 P4 的模型上逐项替换归一化、注意力头和前馈计算，弄清 RMSNorm、GQA、SwiGLU 与权重绑定改变了什么。[P9 生成、采样与对话格式](/principles/generation/) 把一次预测接成可停止的生成循环；[P10 KV cache](/principles/kv-cache/) 证明只计算新增 token 时，怎样保持与整段重算相同的结果。最后，[P11 组装完整现代 Decoder](/principles/complete-transformer/) 用一个更接近现代结构的两层模型，将前面分别推导的模块放到同一条训练和缓存生成路径中。P4 解决基础计算能否闭合，P11 检查现代组合能否仍然闭合。

## 按问题选择入口

首次学习按章节顺序走。已有注意力基础，只想弄清位置时，从 [P3](/principles/attention/) 核对 causal mask 和分数的定义，再读 P5–P7；只想实现生成，先确认 [P2](/principles/language-modeling/) 的训练目标和 [P4](/principles/decoder/) 的前向过程，再读 P9–P10。要对照现代模型的结构与代码，则继续读 P8 和 P11。各章的手算和脚本检验同一个问题的不同部分，数值断言能核对案例，普遍结论仍要看推导的条件。

进入 P1 前，需要 [M3 向量与矩阵](/math/linear-algebra/) 中的矩阵、轴和索引，以及 [M7 神经网络训练](/math/training/) 中预测与参数更新的关系。[M2 分布与信息量](/math/distributions/) 的 softmax 和交叉熵会在 P2 用到；[M6 反向传播](/math/backprop/) 帮助理解 P4 的梯度。不熟悉数组轴、PyTorch 的自动求导或模块 API，可按遇到的障碍回读 [数组与框架路线](/frameworks/)。

读完 P11，可以进入 [训练与评估](/training/) 处理语料、优化和模型评估，或进入 [推理系统](/systems/) 估算生成成本并研究服务实现。
