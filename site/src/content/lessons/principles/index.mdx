从一段字符串到可训练语言模型，需要连续回答四件事：输入怎样编号，每个位置预测什么，怎样读取合法历史，怎样把损失传回参数。本路线先用 `[BOS,A,B,EOS]` 建立这条链，再分别研究位置和现代结构。原理终章将这些单元放入同一个 `Transformer`，后续训练、适配和系统实验都使用这份实现。

进入路线需要 [M6 向量与矩阵](/math/linear-algebra/) 的轴、点积和索引，以及 [M5 分布与预测损失](/math/distributions/) 的 softmax 与交叉熵。反向传播需要 [M9](/math/backprop/)。数组或 PyTorch API 成为障碍时，按问题回读 [框架路线](/frameworks/)，不必先读完编译等选读内容。

## 先建出第一个预测器

[P1 文本、token 与 embedding](/principles/tokenization/) 从 `猫 sat` 的字节 BPE 走到参数查表，固定 tokenizer 的合并与特殊 ID 契约。为了能手算，[P2 下一 token 预测](/principles/language-modeling/) 明确改用四项教学词表，将 `[BOS,A,B,EOS]` 分成三个移位目标，再训练 bigram。词表更换是例题尺寸的选择，不是复用既有模型权重。

[P3 注意力与多头](/principles/attention/) 补上 bigram 无法读取的历史，先算单头，再处理 causal mask、拆合头和 batch 隔离。[P4 基础 Decoder](/principles/decoder/) 仍用四项文档，把 embedding、位置表、残差、FFN 和 head 连到一次完整前向与反向。到这里已经能训练模型；接下来的结构不是让“不能训练”变成“能训练”的必要条件。

## 逐项解释位置与结构

先沿 [P5 顺序来源](/principles/attention-order/) → [P6 sin/cos](/principles/sinusoidal/) → [P7 RoPE](/principles/rope/) 回答显式位置与因果可见性各做什么。P6 的矩阵指数、P7 的复数写法是选读，不作为后文的必要先修。

结构变化分三章，每次只研究一个单元：[P8 归一化与残差路径](/principles/normalization/) 对照 LayerNorm/RMSNorm 与 Pre/Post-Norm；[P9 查询头共享 K/V](/principles/head-sharing/) 对照 MHA/MQA/GQA；[P10 门控前馈网络](/principles/gated-ffn/) 算清 gate/up 的乘积和预算。权重绑定在完整组装时再引入，因为它连接输入表与输出词表头两种职责。

| 配置 | 基础预测器 P4 | 组合预测器 P13 | 经典分支 P14 |
| --- | --- | --- | --- |
| 条件结构 | decoder-only | decoder-only | encoder–decoder |
| 位置 | 学习式表 | RoPE | 加法 sin/cos |
| norm | Pre-LayerNorm | Pre-RMSNorm | Post-LayerNorm |
| 注意力 | MHA | GQA | MHA、cross-attention |
| FFN | GELU | SwiGLU | ReLU |
| 输入/输出词表表 | 独立 | 参数绑定 | 独立输出 head |

表中的差异是本课程明确选定的实验配置，不是模型类别的必然属性。变更结构或词表后不能直接沿用原权重并期待 logits 不变。

## 两条调用路线在完整模型处汇合

希望理解训练，先完成上述单元，再读 [P13 组装完整 Decoder](/principles/complete-transformer/) 的训练部分。希望理解生成，则从 P4 进入 [P11 生成与采样](/principles/generation/)，完成位置机制后读 [P12 KV cache](/principles/kv-cache/)，最后回到 P13 核对同参数的整段、分块和逐 token logits。P13 的缓存部分需要 P12，页头列出实际先修。

P13 主例改用 `[BOS,春,风,来,EOS]` 和两层模型，目的在于检验组装接口、头宽与残差宽不相等、共享参数和逐层缓存。二维组合手算放在选读 trace 中，不能把两套配置的数值混算。真正文本训练从 [T1 数据与窗口](/training/data/) 到 [T3 文本预训练](/training/pretraining/) 使用 P1 的 tokenizer 工件与同一 Python 模型入口。

[P14 双向 Encoder 与 Cross-Attention](/principles/encoder-cross-attention/) 是独立选读分支：完整源文本与未知目标前缀对应三种可见矩阵，再连接经典参考实验和统一模型。encoder-only 的遮挡监督也在该分支解释，不打断 decoder-only 的首次学习。

## 运行代码与机制实验

各页只展示与问题直接相关的源码片段，完整源码可以展开。`examples/principles/` 保存可运行的教学例与独立手算参考，`src/llms_from_scratch/` 保存训练、生成和机制实验共同使用的实现。机制实验沿原 Transformer Lab 的章节编号运行，例如 `uv run llms-from-scratch chapter --chapter 11` 核对 GQA；该编号是实验 ID，与本站 P9 学习顺序不同。

代码与交互实验各说明实际固定的输入、权重和配置。相同形状只证明接口能接上；共享参数是否正确、缓存是否等价，还要比较同权重的数值和梯度。读完 P13，可进入 [训练与评估](/training/)、[后训练](/post-training/) 或 [推理系统](/systems/)，将已建立的模型用于新问题。
