## 先修与记号

不熟悉 NumPy/PyTorch API 时，先读 [数组与框架 F 路线](/frameworks/)，尤其是 F3 的轴重排、F4 的求导边界和 F5 的模块、嵌入与交叉熵。已有框架经验的读者可直接进入本路线。

需要 [M3 向量与矩阵](/math/linear-algebra/) 中的点积、范数、转置和矩阵乘法，以及 [M7](/math/training/) 的预测与更新闭环。P7 的训练一节用到 [M6](/math/backprop/) 的雅可比转置。P6 的矩阵指数和 P7 的复数写法都是选读；M4 提供导数与有限阶 Taylor，无限级数所需条件在选读处补充，不是实矩阵主线的先修。

这条路线沿用注意力论文的写法：内容向量 $x_i\in\mathbb R^d$ 是列向量，按行堆成 $X\in\mathbb R^{T\times d}$，投影写作 $Q=XW_Q$，其中 $W_Q\in\mathbb R^{d\times d_h}$。它是数学基础里线性层权重 $W\in\mathbb R^{m\times d}$ 的转置布局；换算时先对齐形状，不要因为都叫 $W$ 就直接套用公式。位置下标用 $i,j,p$，虚数单位写作正体 $\mathrm i$。

沿用 [数学导读的跨路线记号](/math/#公式约定每个符号都有形状)：序列长 $T$，历史缓存长 $T_{\mathrm{past}}$，头维度 $d_h$，频率底数 $\beta$，第 $r$ 个二维分块的角频率 $\omega_r$。查询（query）、键（key）、值（value）向量分别写作 $q,k,v$，按行堆成矩阵 $Q,K,V$。未归一化分数（logits）经 softmax 变成权重；token 是分词器产生的基本单位，可以是词、子词或其他片段。键值缓存（KV cache）保存历史键和值；预填充（prefill）处理提示，解码（decode）逐步处理新 token。

## 怎样核对

每个等式都区分两种依据：可以证明的性质，以及人为选择的设计。证明写在正文里；有限数值上的核对交给两个只需 CPU 的脚本。

```sh
python code/principles/position_encoding.py
python code/principles/kv_cache.py
python code/principles/modern_decoder.py
```

前四章还有分词往返、标签移位、有效位置损失、完整模型因果性与参数计数的验证。位置脚本检查置换、相对核与梯度；缓存脚本既比较 RoPE 单层，也比较完整三层 Decoder 的词表 logits。断言核对有限算例，正文证明交代一般关系的假设。读完可进入 [训练与评估](/training/) 建立完整训练与 checkpoint，或进入 [推理系统](/systems/) 给生成记账。
