[P1](/principles/tokenization/) 已经将文本变成 token ID，[M5](/math/distributions/) 说明了怎样用 logits 和交叉熵训练一次分类。现在假设只拿到一段文档 `[BOS,A,B,EOS]`：怎样让模型从这四个 ID 学到下一 token 预测？本章会一直使用这段文档，把它变成三个分类问题，算出损失，再训练一个最小模型。这里还不需要注意力。

令词表为 `BOS=0,A=1,B=2,EOS=3`。BOS 标记文档开始，EOS 标记结束；它们和 A、B 一样占据词表中的类别。这个人为词表只用于把每一步算清楚，不代表真实 tokenizer 会按字符切分。

## 序列概率：为什么每个位置都是一次条件预测

如果模型要给整段文档分配概率，就得先回答：BOS 后是 A 的概率是多少？已看到 BOS、A 后是 B 的概率是多少？接下来结束的概率又是多少？使用 [M2 贝叶斯与序列概率](/math/bayes/) 的概率链式法则，就把它们相乘：

$$
P(A,B,EOS\mid BOS)
=P(A\mid BOS)P(B\mid BOS,A)P(EOS\mid BOS,A,B).
$$

一般地，设 $u_0=BOS$，后续 $T$ 个 token 为 $u_1,\ldots,u_T$，则

$$
P(u_1,\ldots,u_T\mid u_0)
=\prod_{i=0}^{T-1}P(u_{i+1}\mid u_0,\ldots,u_i).
$$

等式来自条件概率，**没有假设 token 彼此独立**。第 $i$ 项允许依赖截至 $i$ 的全部历史，却不能依赖尚未出现的 $u_{i+1}$。自回归（autoregressive）语言模型用参数 $\theta$ 近似这些条件分布。它在每个位置输出四个 logits，即 softmax 前各词表类别的原始分数；沿类别轴做 softmax，才得到和为 1 的概率。

常见的 $P_\theta(x_t\mid x_{<t})$ 表达同一个任务：$x_t$ 是待预测的 token，$x_{<t}$ 是之前的全部 token。本章用 $u$ 记 token ID，避免与数学路线中的实数输入向量 $x$ 混淆。语言模型学的是每种历史下的条件分布，而非仅靠一个固定的词频表。

我们明确以 BOS 为给定条件，预测 A、B 和 EOS。若没有 BOS，模型还需要另外定义第一个 token 的概率；不能漏掉该项却把结果称为整份文档的无条件概率。

## 标签移位：同一段文档怎样产生三个样本

位置 $i$ 的输入是当前 token，目标是**下一** token。将文档错开一格便得到训练对：

| 位置 $i$ | 当前位置输入 | 该位置应能利用的历史 | 目标 | 是否计入损失 |
| --- | --- | --- | --- | --- |
| 0 | BOS | BOS | A | 是 |
| 1 | A | BOS、A | B | 是 |
| 2 | B | BOS、A、B | EOS | 是 |

因此 `inputs = [BOS,A,B]`，`targets = [A,B,EOS]`。位置 1 输入 A，预测 B；用 A 作为该位置的标签，会让模型学习复制输入。EOS 是最后一个目标；这段样本不需要再用 EOS 预测一个未定义的后继。

批量代码常写 `inputs = documents[:, :-1]`、`targets = documents[:, 1:]`。批大小为 $B$、输入长度为 $T$ 时，两者形状都是 $(B,T)$，logits 的形状是 $(B,T,V)$。这里的 $B$ 是批大小，和例子中的 token 名称 `B` 没有关系。若某模型接口已在内部移位，调用方不可再移位一次；必须先确认接口约定。

### Teacher forcing 解决训练时的等待问题

训练时，位置 2 的真实历史 BOS、A、B 已经在文档中，不必等模型先生成 A、B。这种提供真实历史的方式叫 teacher forcing。能读取完整历史的模型可使用这些已知项；本章后面的 bigram 只取最后一项 B。三个位置于是可以在一次前向传播里计算；即使最后一个位置的目标是 EOS，位置 0 和 1 也绝不能提前读到各自的目标。

teacher forcing 只提供**已经发生的历史**，并不允许偷看未来。bigram 模型天生只读当前位置；后续能读取多个位置的模型，需要额外限制可见位置。[P3](/principles/attention/) 将把这项限制放进注意力计算。

## 逐位置负对数似然：怎样评价三个预测

设模型分别给正确目标 A、B、EOS 分配概率 $0.6,0.7,0.6$。这三项是同一文档上三个条件分布中的概率，不要求三者相加为 1。整段文档的条件概率是 $0.6\times0.7\times0.6=0.252$。训练通常最小化负对数似然（negative log-likelihood，NLL）：对数把序列概率的乘积变成逐位置损失的和，

$$
-\ln P_\theta(A,B,EOS\mid BOS)
=-\ln0.6-\ln0.7-\ln0.6
\approx1.378326.
$$

三个位置平均后约为 $0.459442$。单位置的 $-\ln p(\text{目标})$ 就是 [M5](/math/distributions/) 中独热标签的交叉熵。不能先平均正确类别概率 $0.633333$ 再取负对数：对数不是线性运算。四项词表上始终均匀预测的单位置 NLL 是 $\ln4\approx1.386294$，供这个固定词表作数值基线。

### 有 PAD 时，分母应是什么

为了和别的文档组成等长 batch，可以在三个预测位置后补两个 PAD 占位。PAD 不增加待预测的真实目标。若把 PAD ID 作为模型输入，词表必须为它保留合法 ID。

本章的数值检查只在 logits 和目标张量后补无效位置，不调用模型处理 PAD 输入。这样可以单独检验损失的分母。

用 $m_{b,i}\in\{0,1\}$ 标记第 $b$ 条文档的位置 $i$ 是否有有效目标。有效目标数为 $N_{\mathrm{valid}}=\sum_{b,i}m_{b,i}$，平均损失为

<KeyEq label="有效位置平均">

$$
L=-\frac{1}{N_{\mathrm{valid}}}\sum_{b,i}m_{b,i}\ln p_{b,i,y_{b,i}},
\qquad N_{\mathrm{valid}}>0.
$$

</KeyEq>

$y_{b,i}$ 是**移位后**的目标 ID，$p_{b,i,c}$ 是该位置对词表类别 $c$ 的预测概率。对本例，loss mask 是 `[1,1,1,0,0]`；不管补几个 PAD，分子仍是 $1.378326$，分母仍是 3。若错误地除以扩展后的长度 5，损失和对应梯度都会缩小为原来的 $3/5$。若整个评估集没有有效目标，就没有可定义的平均 NLL 或 PPL。训练时先累计损失和与有效数；一个局部 batch/rank 无目标可以贡献可微零，但若整个更新窗口的有效数为零且无其他目标，应跳过整次参数更新，不执行 AdamW 的权重衰减或改变优化器步数。

损失 mask 只决定哪些**预测位置**进入目标。把 prompt 的目标排除，并不意味着回答位置不能读取 prompt；这个区别在 [H1](/post-training/instruction-tuning/) 还会用到。

## Cross Entropy Loss：序列 NLL 怎样变成分类接口

每个有效位置的目标 ID $y_{b,i}$ 对应一个 one-hot 分布 $q_{b,i,c}=\mathbf1[c=y_{b,i}]$。按 [M5](/math/distributions/) 的定义，词表上的交叉熵为

$$
\ell_{b,i}=-\sum_{c=0}^{V-1}q_{b,i,c}\ln p_{b,i,c}
=-\ln p_{b,i,y_{b,i}}.
$$

one-hot 让求和只保留正确 token 的一项。因此先沿词表轴算每个位置的交叉熵，再对有效位置求平均，恰好得到上面的 $L$。这是最大似然目标通过分类接口实现的原因；词表类别数没有进入平均分母。

PyTorch 的 `F.cross_entropy` 接收原始 logits；对于 $(B,T,V)$ 的输出，可以把有效位置选成 $(N_{\mathrm{valid}},V)$，并提供同样选出的目标 ID：

```python
import torch
from torch.nn import functional as F

# logits: [B, T, V], targets: [B, T], valid: [B, T] bool
if not valid.any():
    raise ValueError("a loss needs at least one valid target")
loss = F.cross_entropy(logits[valid], targets[valid])
```

统一实现先选有效目标，再输出 `TokenLoss(loss_sum, valid_count)`。调用 `.mean()` 要求有效数大于零；跨文档、梯度累积或多 rank 先加分子和分母，再求平均。无效 ID 必须在索引概率前排除，不能先用 PAD 目标索引再指望乘零消除错误。默认无类别权重、无标签平滑、使用类别索引目标时，该接口与逐位置 NLL 相等；增加权重或 label smoothing 会改变目标，不能直接拿修改后的训练损失计算标准 PPL。

真实语言中同一历史可能对应多种后继。one-hot 只表示本次观测，不表示真实条件熵为零。若真实分布为 $P$、模型为 $Q_\theta$，固定评估协议下的期望损失为

$$
\mathbb E_{h\sim P}H(P(\cdot\mid h),Q_\theta(\cdot\mid h))
=H_P(U\mid \mathit{History})
+\mathbb E_{h\sim P}D_{\mathrm{KL}}(P(\cdot\mid h)\Vert Q_\theta(\cdot\mid h)).
$$

这里 $h$ 是真实历史，$U$ 是真实下一 token，$\mathit{History}$ 是历史随机变量。该式沿用 [M4 条件熵与 KL](/math/information/)：模型改进可减少分布不匹配的部分，目标自身的不确定性仍可能保留。训练集的有限样本均值只是这个期望的估计。

## Perplexity：平均负对数概率怎样换成可比较的数

使用自然对数、对 $N_{\mathrm{valid}}$ 个有效 token 计算未经加权的平均 NLL 时，困惑度（perplexity，PPL）定义为

<KeyEq label="交叉熵到困惑度">

$$
\operatorname{PPL}
=\exp(L)
=\left(\prod_{(b,i):m_{b,i}=1}\frac{1}{p_{b,i,y_{b,i}}}\right)^{1/N_{\mathrm{valid}}}.
$$

</KeyEq>

最后一步使用 $\exp(\sum\ln a_i/N)=(\prod a_i)^{1/N}$。PPL 是正确目标概率的几何平均数的倒数；它保留了 NLL 的排序，但换了刻度。三个目标概率 $0.6,0.7,0.6$ 的几何平均约为 $0.631636$，所以 $L\approx0.459442$、$\operatorname{PPL}=0.252^{-1/3}\approx1.583190$。

若在 $C$ 个类别上始终均匀预测，$L=\ln C$，PPL 恰好为 $C$；这给出“等效均匀候选数”的参照，但不等于实际候选数或错了多少个 token。离散 token 的 PPL 至少为 1；模型给某个真实目标零概率时为无穷大。模型错误地给真值极小概率时，PPL 也可以大于词表大小。若损失用以 2 为底的对数，单位是 bit，应计算 $2^L$，而非 $e^L$。

评估多份文档时，先累计所有有效位置的 NLL 总和与 token 数，再计算一次指数。不能平均文档 PPL；文档长度不同时，也不能不加权地平均文档平均 NLL。tokenizer、数据划分、EOS、上下文长度和窗口计分方式都影响结果，比较模型时必须保持这些约定一致。低训练 PPL 只说明训练数据拟合得好，验证集的预测能力和下游任务表现仍需分别评估。

先保持 A、B、EOS 三个计分目标，将 PAD 数从 2 调到 5。数组长度增加，但损失和仍为 `1.378326`，分母仍为 `3`，PPL 仍为 `1.583190`。

接着取消“计分目标 B”。分母应变成 2，平均 NLL 变成 $-\ln0.6\approx0.510826$。此时剩余概率的乘积只覆盖两个目标，已不是完整文档概率。最后取消全部目标，检查平均 NLL 与 PPL 显示为未定义。分类接口与忽略位置归约见 [F5](/frameworks/modules-and-losses/)。

## Bigram：先训练一个只有查表能力的模型

现在需要把“给定历史预测下一项”落实为可训练的参数。bigram 模型只保留历史的最后一个 token。设 $W\in\mathbb R^{4\times4}$ 是 logits 表，输入 ID 为 $u$ 时选择第 $u$ 行，再对这一行做 softmax：

$$
z_c=W_{u,c},\qquad
p_\theta(v=c\mid u)=\frac{e^{z_c}}{\sum_{k=0}^{3}e^{z_k}}.
$$

这是一种条件概率模型，但它施加了更强的近似：$P_\theta(B\mid BOS,A)$ 只由 A 决定，$P_\theta(EOS\mid BOS,A,B)$ 只由 B 决定。用于本例时，BOS 行要预测 A，A 行要预测 B，B 行要预测 EOS；EOS 行没有出现在输入中，因此本样本无法训练它。

先把 $W$ 的所有元素设为零，四类概率各为 $1/4$，三个位置的平均 NLL 是 $\ln4$。怎样知道该提高哪个表格数值？对有效位置的 logit $z_{b,i,c}$ 求导，令 $p_{b,i,c}=\operatorname{softmax}(z_{b,i,:})_c$，由 [M10 神经网络训练](/math/training/) 的 softmax 交叉熵导数与平均因子可得

$$
\frac{\partial L}{\partial z_{b,i,c}}
=\frac{m_{b,i}}{N_{\mathrm{valid}}}
\big(p_{b,i,c}-\mathbf1[c=y_{b,i}]\big).
$$

在位置 0，正确类 A 的 logit 梯度是 $(1/4-1)/3=-1/4$，其余三类各是 $(1/4)/3=1/12$。用学习率 $\eta=1$ 做一步 SGD 后，BOS 行的 A 列变成 $1/4$，其他列变成 $-1/12$；A 行和 B 行对各自目标做同样的更新。新正确类别概率是

$$
\frac{e^{1/4}}{e^{1/4}+3e^{-1/12}}
=\frac{e^{1/3}}{e^{1/3}+3}\approx0.317501.
$$

它高于原来的 $0.25$，所以这一步让训练样本的 NLL 下降。被 loss mask 排除的位置对应的 logit 梯度为零。若同一个输入 ID 在多处出现，对共享的 $W$ 行还须把那些位置的梯度**相加**，和 [M9](/math/backprop/) 的共享参数反向传播一致。

可训练不等于具备长历史能力。两个历史 `BOS,猫,吃` 和 `BOS,人,吃` 都以“吃”结尾，bigram 对下一 token 必须给出相同分布；即使有足够训练数据，也无法根据更早的“猫”与“人”改变预测。[P3](/principles/attention/) 将解决怎样读取更早位置。若某输入 ID 从未在训练语料出现，它的表格行也没有由数据决定；不能把随机输出当成学到的语言规律。

## 训练和生成：历史由谁提供

训练时，我们一次给出真实输入 `[BOS,A,B]`，并用三个真实目标计算损失。生成时只有起点 `[BOS]`：先从 BOS 行的概率选择一个 token，再把**模型选出的** token 接到历史后面，重复直到 EOS 或长度上限。一个针对本样本已训练的 bigram 可能依次选择 A、B、EOS，但它每一步仍只查最后一个 ID 的行。训练时可并行评价多个已知目标，生成时下一个输入依赖上一步的输出。

生成偏离真实历史后，模型可能碰到训练时未见过的转移。把这段文档拟合得很准，并不能证明它会生成自然语言，也不能说明验证集效果。完整采样策略在 [P11](/principles/generation/)，独立数据上的评估在 [T4](/training/evaluation/)。

## 三类 mask：目标和可见历史分别由谁控制

本章的 bigram 只有损失 mask：它只查当前位置的 ID，不存在跨位置注意力。后续模型一次读取多个位置时，还会出现两种**注意力 mask**。仍以输入 `[BOS,A,B,PAD,PAD]` 为例：

| mask | 作用对象 | 位置 2 的效果 |
| --- | --- | --- |
| causal mask | 查询位置 $i$ × 键位置 $j$ | B 可以读 BOS、A、B，不能读后面的 PAD 或任何未来 token |
| padding attention mask | 查询位置 $i$ × 键位置 $j$ | 所有查询都不能把 PAD 键当成有效历史 |
| loss mask | 每个预测目标位置 $(b,i)$ | 只让 A、B、EOS 的三个目标进入损失与分母 |

causal mask 保证 $j\le i$，padding attention mask 剔除无内容的键；两者一起决定可读历史。loss mask 不控制读什么。即便位置 0 的目标 A 已在训练张量中，位置 0 的注意力也不能读取位置 1 的输入 A，否则可以直接抄答案。允许位置 0 读取自身输入 BOS 则没有泄漏。

右侧补 PAD 时，有效位置不会需要读取尾部 PAD；但若在左侧补 PAD，某些 PAD 查询可能没有任何有效键，全屏蔽行上的 softmax 没有定义。实现需要显式处理无效查询，而不是指望 loss mask 自动消除前向计算中的 NaN。[P3](/principles/attention/) 将具体构造和验证注意力 mask。

## 常见误区

- 把当前输入 ID 当目标，训练出复制任务；检查 BOS 位置是否预测 A。
- 以为链式分解要求各位置独立；实际上后一项可依赖更长历史，bigram 只是主动限制表达能力。
- 用含 PAD 的总长度作有效位置均值的分母；这会改变目标尺度与梯度。
- 以为损失 mask 能代替 causal mask；模型仍可能偷看未来输入。
- 用同一训练文档的低 NLL 宣称模型有语言能力；还需独立数据和明确评估约定。

<details>
<summary>如果第二个目标 B 无效，其余正确目标概率仍是 0.6、0.6，新的平均 NLL 与 A 行的梯度分别是什么？</summary>

有效位置数由 3 变成 2，平均 NLL 是 $(-\ln0.6-\ln0.6)/2=-\ln0.6\approx0.510826$。A 行只在位置 1 被使用且该位置无效，所以这个样本对 A 行的梯度为零；BOS 和 B 行仍可更新。不能只去掉分子的一项，却沿用分母 3。

</details>

<details>
<summary>把文档改成 [BOS,A,A,EOS]，写出输入、目标和 bigram 共享行 A 的梯度来源。</summary>

输入是 `[BOS,A,A]`，目标是 `[A,A,EOS]`。A 行在位置 1 和 2 各被读取一次，分别用于预测 A 与 EOS；它们对同一行的梯度相加，不能只保留最后一次。若该行初始 logits 为零，两个位置各带 $1/3$ 的平均因子，A 列梯度为 $(-3/4+1/4)/3=-1/6$，EOS 列也为 $-1/6$，BOS 与 B 列各为 $(1/4+1/4)/3=1/6$。

</details>

<details>
<summary>模型在位置 0 看到 BOS 后给 A 的概率为 0.99，但它的注意力同时读取了位置 1 的输入 A。这能证明下一 token 预测学得好吗？</summary>

不能。位置 1 的 A 正是位置 0 的标签，训练时可读到却在生成首项时尚不存在。应检查 causal mask 是否禁止位置 0 读取位置 1，再在无泄漏数据上评估；仅降低 loss mask 范围不能阻止这种泄漏。

</details>
