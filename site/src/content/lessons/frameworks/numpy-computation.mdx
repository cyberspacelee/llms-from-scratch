[F1 NumPy 数组](/frameworks/numpy-arrays/) 让我们看清 shape、索引和存储。下一步，数组表达式即使能运行，结果 shape 也正确，仍可能沿错轴计算。本章用固定的两条记录，把每次运算写成三个问题：输入轴代表什么，哪条轴被复用或消去，某个输出元素应是多少。矩阵乘的数学定义见 [M6](/math/linear-algebra/)，方差的统计含义见 [M3](/math/probability/)。

$$
X=\begin{bmatrix}1&2&3\\4&5&6\end{bmatrix}
\in\mathbb R^{B\times d},\qquad B=2,\ d=3.
$$

```python
import numpy as np
X = np.array([[1, 2, 3], [4, 5, 6]], dtype=np.float64)
```

轴 0 是样本，轴 1 是特征。一路跟踪 `X[1,2]=6`：任何声称处理第二条样本第三项特征的输出，都必须能追溯到这个数。我们会从偏置开始，完成按行统计、线性映射、类别选择和 softmax。

## 广播：同一组数沿哪条轴复用

给每个特征加偏置 `b=[10,20,30]`。目标是 $Y_{i,j}=X_{i,j}+b_j$，即两条样本都使用同一个 $b_j$。广播（broadcasting）把两个形状从尾轴向前配对；每对长度必须相等，或有一方为 1，缺失的前导轴视作 1。故 `(2,3)+(3,)` 得到 `(2,3)`：

$$
Y=X+b=\begin{bmatrix}11&22&33\\14&25&36\end{bmatrix}.
$$

例如 `Y[1,2]=6+30=36`。偏置沿样本轴复用。若要给每条样本各加 100、200，目标是 $X_{i,j}+r_i$，必须把 $r$ 变成 `(2,1)`，写 `X + np.array([100,200])[:,None]`，得到 `[[101,102,103],[204,205,206]]`。直接用 `(2,)`，当前尾轴 3 与 2 不兼容而报错；若特征数恰巧也是 2，它反而会成功并按特征加偏移。

广播通常不预先复制小输入，但运算结果仍占空间：`(10000,1)+(1,10000)` 会生成一亿个元素。预测结果 shape 也是估算内存的第一步。下面讲完归约后，用同一个实验分别检查广播与均值的轴。

形状相容还可能隐藏另一种错误：预测值是 `(2,1)`，目标是 `(2,)`，相减得到 `(2,2)`，把每条预测与两条目标都配了对。NumPy 只决定怎样广播，不知道哪个轴才是样本。

## 归约：合并哪条轴，留下哪条轴

现在要让每条样本减去自己的特征均值。`axis` 指被合并的轴，不是保留的轴。`X.mean(axis=1)` 沿每行的三项特征求均值，得到 `[2,5]`；`axis=0` 沿两条样本求均值，得到每项特征一个值 `[2.5,3.5,4.5]`。两者都是一维均值，却回答不同问题。

按行中心化后，我们还要从原行的三个位置都减去这一行的均值。`keepdims=True` 将被归约的轴保留为长度 1，计算范围和数值不变：

<KeyEq label="每条样本沿特征轴中心化">
$$
\mu_i=\frac1d\sum_{j=0}^{d-1}X_{i,j},\qquad
C_{i,j}=X_{i,j}-\mu_i.
$$
</KeyEq>

```python
row_mean = X.mean(axis=1, keepdims=True)  # [[2], [5]], shape (2,1)
C = X - row_mean                         # [[-1,0,1], [-1,0,1]]
```

`C[1,2]=6-5=1`，并且每行之和为零。这两个检查一局部、一整体。去掉 `keepdims` 得到 `(2,)`，当前无法从 `(2,3)` 相减；换成方阵却可能运行成功并减错方向。`axis=None` 合并全部元素，整体均值为 3.5。对高阶输入 `(B,T,d)`，若每个 token 要沿特征求均值，就用最后一轴 `axis=-1`，不能顺手合并时间或 batch。

下面先选“加特征偏置”，手算输出 `[1,2]` 的值 36，再改为“加样本偏置”，核对同一位置是否变为 206。选“加错误形状”前，先指出哪一对轴不兼容。

然后切换为“mean 归约”，选 `axis=1`，比较勾选与取消 `keepdims` 时的输出。两次值都应为 2、5；预测哪一种形状能直接从 X 的每行减去，再看读数。最后选择 `axis=0`，说明此时每个均值对应哪个特征。

### 方差沿用同一条归约轴

两行的均值分别为 2、5，平方偏差都为 `[1,0,1]`。NumPy 的 `ddof` 指从归约元素数中扣除多少作为分母：

$$
v_i=\frac{\sum_{j=0}^{d-1}(X_{i,j}-\mu_i)^2}{d-\mathrm{ddof}}.
$$

`X.var(axis=1,ddof=0)` 是 `[2/3,2/3]`，描述当前三项的平均平方偏差；`ddof=1` 是 `[1,1]`，在相应随机抽样假设下可用于估计总体方差。`std` 是所选方差的平方根，也必须明确轴与 `ddof`。神经网络层统计当前激活时，不能仅因统计课使用过 $d-1$ 就照搬 `ddof=1`。当归约轴为空或 $d\le\mathrm{ddof}$，正常的统计分母不存在，上层需要定义处理策略。

## 矩阵乘：消去特征轴，留下样本与输出

中心化使本例的两行都成为 `[-1,0,1]`，抹掉了它们相差 3 的信息。为了观察映射如何区分两条原始输入，以下回到未中心化的 $X$。两个输出通道的权重按行存放：

$$
W=\begin{bmatrix}1&0&-1\\2&1&0\end{bmatrix}
\in\mathbb R^{m\times d},\qquad m=2.
$$

每个输出都是一条样本与一行权重在同一特征位置相乘，再沿特征求和。$X$ 的尾轴 $d$ 必须与权重的特征轴 $d$ 相接，因此先转置 $W$：

<KeyEq label="批线性映射">
$$
Z=XW^\top\in\mathbb R^{B\times m},\qquad
Z_{i,j}=\sum_{k=0}^{d-1}X_{i,k}W_{j,k}.
$$
</KeyEq>

`X @ W.T` 的 shape 是 `(2,3)@(3,2)->(2,2)`。首行两个输出分别是 $1\cdot1+2\cdot0+3\cdot(-1)=-2$ 和 $1\cdot2+2\cdot1+3\cdot0=4$；第二行是 $-2,13$。所以 $Z=[[-2,4],[-2,13]]$。输出第一轴仍是样本，第二轴已经从特征换成输出通道，不能因为长度同样为 2 就沿用旧名字。

```python
W = np.array([[1, 0, -1], [2, 1, 0]], dtype=np.float64)
Z = X @ W.T
assert Z.tolist() == [[-2, 4], [-2, 13]]
```

<Figure src="frameworks/numpy-axes.svg" alt="X 的样本轴与 W 的输出轴保留，共同特征轴相乘求和" minWidth="30rem">按相同特征位置 $k$ 配对、相乘并求和；结果的行来自 $X$，列来自 $W$。</Figure>

下面选样本行 b=1、输出通道 m=1，先写出第二条样本与第二行权重的三个乘积。将 k 从 0 调到 2，逐项核对；观察高亮项改变时，输出是否始终为 13。k 只选择查看位置，不改变三项求和的范围。

<NumpyContractionLab client:visible />

因为本例 $X,W$ 碰巧都是 `(2,3)`，`X*W` 也能运行，得到 `[[1,0,-3],[8,5,0]]`、shape `(2,3)`。`*` 保留逐位置乘积；`@` 消去共同特征轴。检查一个输出的来源比只看 shape 更可靠。

`np.einsum('bd,md->bm',X,W)` 将同一关系写在标签里：`b` 是样本、`m` 是输出，重复的 `d` 不出现在结果中，表示沿特征求和。若写成 `'bd,md->bmd'`，会得到 `(2,2,3)` 的乘积集合，仍需沿末轴求和。这个二维例子直接用 `@` 更易读；复杂轴关系可用 `einsum` 核对。高阶 `matmul` 则把最后两轴当作矩阵轴，前导轴按广播规则匹配。

## 按行收集：位置、数值与网格

$Z$ 的两列可以看作两个候选类别的原始分数，即 logits。要找每条样本分数最大的类别，用 `Z.argmax(axis=1)` 得到位置 `[1,1]`，不是分数。沿同一类别轴收集数值：

```python
choice = Z.argmax(axis=1, keepdims=True)        # [[1], [1]]
picked = np.take_along_axis(Z, choice, axis=1)  # [[4], [13]]
```

`Z[choice]` 会沿第 0 轴取整行，已经换了含义。若分类目标是 `[0,1]`，应整理成 `(B,1)`，再沿类别轴收集，结果为 `[[-2],[13]]`。并列最大值时 `argmax` 返回沿该轴首先出现的位置，这只是 API 的确定性规则。

有时我们想保留整个网格，只替换某些值。`np.where(Z>0,Z,0)` 得到 `[[0,4],[0,13]]`、shape `(2,2)`；布尔索引 `Z[Z>0]` 得到一维 `[4,13]`。`np.clip(Z,0,10)` 得到 `[[0,4],[0,10]]`，限制数值范围，并非选区。`where` 的两个分支表达式会先求值；`np.where(Z!=0,1/Z,0)` 在零处仍可能除零。需要避免非法运算时，可用 `np.divide` 的 `where` 参数和已初始化的 `out`。

## 拼接与堆叠：延长轴还是添加轴

若另一批数据也有三个特征，`np.concatenate([X,X],axis=0)` 沿现有样本轴增加记录，shape `(4,3)`。若两份 $X$ 表示同一批样本在两个时刻的观测，`np.stack([X,X],axis=0)` 添加时间轴，shape `(2,2,3)`，依次为时刻、样本、特征。元素数相同，坐标含义却不同；不能随意 `reshape` 冒充另一种操作。沿特征轴拼接得到 `(2,6)`，前提是两份数据的样本行一一对应。

本例时间轴与样本轴长度恰好都为 2，不足以靠 shape 分辨它们。应跟踪 `stacked[time,sample,feature]` 对应哪一项。若尾部 batch 只有一条样本，沿样本轴 `concatenate` 仍可得到 `(3,3)`，但 `stack` 要求各份输入 shape 相同。

## Softmax：沿类别轴完成最后一次归约

把 $Z$ 的每行 logits 变成两个类别的概率。直接对大分数取指数可能溢出。令 $L=Z+1000$：这给每行两个类别都加上同一常数，概率本应不变，但直接计算 `np.exp(L)` 会溢出。先减去该行最大值 $a_i$，指数比例不变且最大指数为 1：

<KeyEq label="逐行稳定 softmax">
$$
a_i=\max_j L_{i,j},\qquad
P_{i,j}=\frac{\exp(L_{i,j}-a_i)}
{\sum_k\exp(L_{i,k}-a_i)}.
$$
</KeyEq>

```python
logits = Z + 1000
shifted = logits - logits.max(axis=1, keepdims=True)
weights = np.exp(shifted)
probabilities = weights / weights.sum(axis=1, keepdims=True)
```

两行移位后分别为 `[-6,0]`、`[-15,0]`；第一行类别 1 的概率为 $1/(1+e^{-6})\approx0.9975$，第二行约为 $0.9999997$。`max` 与 `sum` 都沿类别轴 1，保留 `(B,1)`，因此每行概率和为 1。若误用 `axis=0`，每列的和可能为 1，看着也像“归一化”，却让一条样本依赖另一条样本。改变第二行 logits 时，第一行概率必须不变；这是比只检查非负更有力的错轴测试。

本章的基础函数要求类别轴非空，输入 logits 有限。整行都是负无穷时会发生负无穷减负无穷，上层须先定义没有可用候选的处理策略。概率和损失的含义见 [M5](/math/distributions/)。

### 选读：局部随机生成器

要生成实验输入，`rng=np.random.default_rng(7)` 创建局部生成器，`rng.normal(size=X.shape)` 按 `(2,3)` 生成样本。同一环境、同一种子、相同调用顺序可复现该次样本；第二次调用同一个 `rng` 会推进状态。核心计算仍使用显式 $X$，不靠恰巧抽出的随机值定义轴。

## 常见误区

- **广播成功就说明轴语义正确。** 长度恰巧相等时，样本偏移可能被当作特征偏移；写出一个元素的下标关系。
- **`axis=1` 表示保留第 1 轴。** 归约会合并这一轴；`keepdims` 只留长度为 1 的位置。
- **相同 shape 的乘法可代替矩阵乘。** 本例 `X*W` 和 `X@W.T` 都能运行，前者没有沿特征求和。
- **概率非负就说明 softmax 正确。** 还要检查行和为 1，以及改变一行不影响另一行。

## 练习与核对

<details>
<summary>对 X 减去每列均值，应沿哪个轴归约？两行结果分别是什么？</summary>

沿样本轴 `axis=0` 归约，`X.mean(axis=0,keepdims=True)=[[2.5,3.5,4.5]]`。相减得到 `[[-1.5,-1.5,-1.5],[1.5,1.5,1.5]]`，每列和为零。这里消去样本轴，保留特征轴。
</details>

<details>
<summary>若 X 改为三条两特征样本，shape (3,2)，按行与按列求均值后各应保留什么 shape？</summary>

按行沿特征轴 `axis=1` 求均值并保留轴，结果 `(3,1)`；按列沿样本轴 `axis=0` 求均值并保留轴，结果 `(1,2)`。二者都能广播回 `(3,2)`，但含义不同，不能只看最终 shape。
</details>

<details>
<summary>目标类别为 [0,1]，怎样从 Z 中收集每条样本的目标分数？</summary>

用 `target=np.array([0,1])`，再计算 `np.take_along_axis(Z,target[:,None],axis=1)`，得到 `[[-2],[13]]`。新增的长度 1 轴表示每条样本只取一个类别；`Z[target]` 则沿样本轴选整行。
</details>

<details>
<summary>怎样只改第二行，判断 softmax 是否错用了 axis=0？</summary>

先保存 `softmax(Z)[0]`，再把 `Z[1]` 改为任意另一对有限 logits。正确按行计算时第一行不变；若沿轴 0 求最大值及指数和，第二行参与第一行所在列的归一化，第一行通常会改变。还应检查每行和为 1。
</details>

<details>
<summary>两份 X 沿 axis=0 做 concatenate 与 stack，各是什么 shape？何时不能 stack？</summary>

`concatenate` 延长样本轴，得到 `(4,3)`；`stack` 新建“第几份”的轴，得到 `(2,2,3)`。若第二份是 `(1,3)` 的尾部小 batch，沿样本轴仍能拼成 `(3,3)`，但两份 shape 不同，不能 stack。
</details>
