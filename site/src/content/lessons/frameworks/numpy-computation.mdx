两个样本各有三个特征，输入 $X=[[1,2,3],[4,5,6]]$。你想给每个特征加偏置，再减去每个样本自己的均值，最后映射成两个输出。Python 循环可以逐项完成这些工作；数组代码通常更短，却也更容易把“跨样本”写成“跨特征”，或在广播中悄悄构造一个更大的结果。

## 广播规则：从尾轴向前对齐

广播（broadcasting）允许大小为一或缺失的轴在逐元素运算中与另一数组匹配。它解决的具体问题是：一组特征偏置需要加到每个样本上，是否必须先手工复制成整个批的形状？NumPy 可以直接表达这个运算，但必须先满足形状规则。

把两个形状从最后一项开始对齐，缺失的前导轴按长度一理解。每一对轴必须长度相等，或者至少一个长度为一；否则该逐元素运算不成立。对兼容的非空轴，结果长度取匹配的公共长度。不要从轴 0 开始配对，也不要因为元素总数恰好相同就判断能广播。

输入 X 的 shape 是 `(2,3)`，偏置 `b=np.array([10,20,30])` 的 shape 是 `(3,)`。尾轴 3 与 3 匹配，前面的 2 与缺失轴所代表的 1 匹配，所以输出 `(2,3)`：

$$
Y_{i,j}=X_{i,j}+b_j,
\qquad Y=\begin{bmatrix}11&22&33\\14&25&36\end{bmatrix}.
$$

这里 $i$ 是样本号，$j$ 是特征号。偏置随特征变化、在样本间重复使用，正是需要的语义。代码 `X+b` 没有把 b 的三项赋予新的样本含义；它只是按照尾轴规则解释这个输入。

若每个样本有自己的偏移 100、200，应给偏移 shape `(2,1)`，写 `X+np.array([[100],[200]])`，得到 `[[101,102,103],[204,205,206]]`。尾轴 3 与 1 匹配，样本轴 2 与 2 匹配；每行的偏移在该行三个特征上复用。写成 `(2,)` 则尾轴 3 与 2 冲突，报 `ValueError`。

实验的前三种计算方式分别展示特征偏置、样本偏置和错误形状。输出格直接列出计算结果，错误模式不生成一张看似合理的结果图，而显示冲突的尾轴。归约模式稍后再用：它会同时展示输出数字与 shape，帮助区分“少一个轴”和“保留长度一的轴”。

广播通常不需要先把较小输入实体复制成较大数组，但算术输出仍需要空间。`(10000,1)` 与 `(1,10000)` 相加可以生成一亿个元素，两个输入很小不代表结果很小。`broadcast_to` 可以返回共享输入的只读广播视图，也不表示下一次算术会免费。先推导结果 shape，再估算元素数和字节数，尤其要留意无意出现的外积式扩展。

一个常见陷阱是样本数恰好等于特征数。假设 X 是 `(3,3)`，每样本均值是 `(3,)`，直接 `X-mean` 可能不报错，却把三个均值对齐到特征轴，减错方向。测试只用方阵容易隐藏这种错误。本章使用 `(2,3)`，让错误方向立即暴露；真实代码还应写清轴名，不能把“不报错”当作语义正确。

## 归约轴：删掉哪个坐标，保留哪些结果

归约（reduction）把某个范围的多个元素合成一个结果。`sum`、`mean`、`max` 等 API 的 `axis` 指定**沿哪条轴合并**，而不是保留哪条轴。对 `(B,d)` 的 X，`axis=0` 合并样本，保留每个特征；`axis=1` 合并特征，保留每个样本。

当前 X 沿轴 0 求均值，结果为 `[(1+4)/2,(2+5)/2,(3+6)/2]=[2.5,3.5,4.5]`，shape `(3,)`。沿轴 1 求均值，结果为 `[(1+2+3)/3,(4+5+6)/3]=[2,5]`，shape `(2,)`。两个结果都是一维数组，但轴所表达的对象完全不同。

```python
X = np.array([[1,2,3],[4,5,6]], dtype=np.float64)
assert X.sum(axis=0).tolist() == [5,7,9]
assert X.sum(axis=1).tolist() == [6,15]
assert X.mean(axis=1).tolist() == [2,5]
```

`axis=None` 合并所有元素，`X.sum()` 得到 21；`axis=(0,1)` 也明确合并这两个轴。高阶数组的 `axis=-1` 表示最后一轴，方便表示“每个位置沿最后特征轴计算”。负轴号不是逆序运算，它只是从末尾数轴。选择一组轴时先列出每条轴的语义，避免把 token 与特征同时合并。

`keepdims=True` 不改变合并范围或数值，它把被归约的轴保留为长度一。`X.mean(axis=1,keepdims=True)` 得到 `[[2],[5]]`，shape `(2,1)`。这样结果可以明确广播回每个样本的特征位置：

$$
\mu_i=\frac1d\sum_{j=0}^{d-1}X_{i,j},
\qquad \widetilde X_{i,j}=X_{i,j}-\mu_i.
$$

本例 $d=3$，两个样本中心化后都得到 `[-1,0,1]`。实现写 `X-X.mean(axis=1,keepdims=True)`，可逐项对应公式。若关闭 keepdims，得到的 `(2,)` 与 `(2,3)` 不能广播；在方阵例子里还可能出现前面说的静默错轴。长度为一的轴在这里携带了位置语义，不是无用的括号。

在实验里切换 `axis=0/1`，再勾选或取消 keepdims，可以看到值不变而 shape 改变。axis 0 输出三项特征均值，axis 1 输出两项样本均值。图中一列或一行的排布对应保留的轴；一维结果不再携带被删除轴的位置，所以回用于广播时要重新明确它应放在哪里。

整数输入也影响归约的类型行为。`mean` 对整数通常使用浮点结果，`sum` 则可能使用整数累计类型；如果总和超出该固定宽度类型范围，就不能当作任意精度整数求和。对于本章数值核对，我们显式转换成 float64。生产模型的 dtype 选择应结合精度、范围与性能，而不是把“更大类型”当作唯一策略。

## 方差约定：相同数据为何得到两个数

`np.var` 先围绕均值计算平方偏差，再用指定分母归约。对一个长度为 $n$ 的序列，NumPy 的 `ddof` 表示分母扣除的自由度数量：

$$
v=\frac{\sum_{j=0}^{n-1}(x_j-\bar x)^2}{n-\mathrm{ddof}}.
$$

默认 `ddof=0`，分母是 n，描述这组数的平均平方偏差。`ddof=1` 使用 n−1，常用于随机样本估计总体方差的修正。它们不是同一个定义，不能只说“算方差”就省略分母。本章区分对当前数据的描述与对抽样总体的估计，统计推导回读 [M1](/math/probability/)。

对 `[1,2,3]`，均值为 2，平方偏差为 `[1,0,1]`。`ddof=0` 得到 $2/3$，`ddof=1` 得到 1。对 X 按轴 1 计算，两行都得到相同结果；因此 `X.var(axis=1,ddof=0)` 为 `[2/3,2/3]`，`ddof=1` 为 `[1,1]`。`std` 对相应方差开平方，也需要明确同一个 ddof。

若 $n\le\mathrm{ddof}$，分母没有所需的有效自由度，不能把输出当作正常估计。空选区的 mean 或 var 也可能产生警告与非有限结果。模型代码遇到全空或全屏蔽行，应先定义策略，而不是盲目继续除法。API 能返回一个数组，不代表你的统计问题有足够数据。

在归一化层中，常见的目标是当前一行元素的统计，而不是抽样总体的无偏方差估计，因此需要核对该层实际约定。不要因为过去统计课用过 n−1 就给所有神经网络方差都设 `ddof=1`。层的规范、轴与 epsilon 才决定要计算哪一个表达式。

## 乘法契约：逐元素乘与收缩特征轴

`*` 是逐元素乘，可以先广播，结果保留匹配后的全部位置。`@` 或 `np.matmul` 表达矩阵乘；二维情况将左矩阵最后一轴与右矩阵倒数第二轴配对、求和，留下输出的两条轴。一个不会自动替代另一个。

沿用 $X\in\mathbb R^{B\times d}$，设权重 $W\in\mathbb R^{m\times d}$，每行是一个输出的特征权重。本章取 $B=2,d=3,m=2$，$W=[[1,0,-1],[2,1,0]]$。批输出为

<KeyEq label="保留样本与输出轴">

$$
Z=XW^\top,\qquad Z_{i,j}=\sum_{k=0}^{d-1}X_{i,k}W_{j,k}.
$$

</KeyEq>

这里 $i$ 是样本、$j$ 是输出通道、$k$ 是相乘后被求和消去的特征位置。`X@W.T` 的形状是 `(2,3)@(3,2)->(2,2)`。第一行的两个输出分别是 $1\times1+2\times0+3\times(-1)=-2$ 和 $1\times2+2\times1+3\times0=4$。第二行得到 −2、13。

<Figure src="frameworks/numpy-axes.svg" alt="X保留样本轴，W保留输出轴，两者共同特征轴相乘求和，输出Z只剩样本与输出" minWidth="30rem">两份输入中相同的特征位置参与乘积；中间沿特征求和；输出保留样本与输出通道。轴含义比字母名称更重要。</Figure>

图中 X 与 W 都是 `(2,3)`，但两个长度为 2 的前轴含义不同。X 的两行是样本，W 的两行是输出权重。因为数值长度碰巧相同，`X*W` 也能运行，得到 `[[1,0,-3],[8,5,0]]`，shape `(2,3)`；它只做六次对应位置相乘，没有做两个输出通道各自的点积。这是只检验“表达式可运行”无法发现的语义错误。

## Einsum：把保留与求和的轴写明

`np.einsum` 用字母标签描述轴之间的对应关系。显式写输出标签的 `np.einsum('bd,md->bm',X,W)` 表达与 `X@W.T` 相同的计算：输入 X 的 b、d 分别代表样本与特征，W 的 m、d 代表输出与特征，结果保留 b、m，共同的 d 不出现在输出中，因此沿 d 求和。

标签不是数组内部注册的名字，也不是数值变量；它们只在这一次表达式内约定轴关系。把 d 改成 k，只要对应关系不变，结果也不变。`'bd,md->bmd'` 则保留 d，输出是 `(B,m,d)` 的乘积集合，还没有求和；再沿最后一轴 sum 才得到 Z。显式输出部分能让你确认究竟消去了哪一轴。

```python
Z = np.einsum('bd,md->bm', X, W)
products = np.einsum('bd,md->bmd', X, W)
assert products.shape == (2,2,3)
assert np.allclose(Z, products.sum(axis=-1))
```

对于简单二维矩阵乘，`@` 通常更熟悉；对于需要明确轴对应的高阶表达式，einsum 可以帮助阅读和核对。不能因为表达式更短就宣称更快。不同实现可能产生不同中间结果，收缩顺序与优化选项也影响工作量。先用显式循环验证数学，再根据实际规模评估实现。

`matmul` 对高阶输入把最后两轴当作矩阵轴，前导轴按广播规则匹配。例如 `(B,T,d)@(d,m)` 得到 `(B,T,m)`。一维输入还有特定的轴提升与移除规则，两个 `(d,)` 用 `@` 得到标量点积。初学阶段可以先把输入写成明确二维，再逐步迁移到高阶；不要把 `np.dot` 的高阶规则与 matmul 混用。

## 条件与收集：保留形状还是压成选中项

`np.where(condition,a,b)` 在每个位置根据条件选择 a 或 b，两分支和条件都要能广播到共同形状。`np.where(X>3,X,-1)` 返回 `[[−1,−1,−1],[4,5,6]]`，保留 `(2,3)`。它与 `X[X>3]` 的一维 `[4,5,6]` 不同；前者是在原网格上选值，后者取出所有满足条件的位置。

```python
masked = np.where(X > 3, X, -1)
clipped = np.clip(X, 2, 4)
# masked = [[-1,-1,-1],[4,5,6]]
# clipped = [[2,2,3],[4,4,4]]
```

`clip` 把小于下界的值替换成下界、大于上界的值替换成上界，保留中间值。这里它限制数值范围，不是选择某段数组，也不是梯度裁剪。下界和上界也有广播规则；API 不替你证明上下界的业务含义，输入边界是否有效应由调用者检查。

`where` 不保证只计算被选择的分支。写 `np.where(X!=0,1/X,0)` 时，`1/X` 通常在传给函数之前就计算了，仍可能除零。需要避免非法运算，可以先筛出非零位置计算，或使用 `np.divide` 的 `where` 参数与明确初始化的 `out`。把控制流的“只执行一支”直觉照搬到数组选值函数，会漏掉警告与非有限值。

`argmax(axis)` 返回最大值的位置，而不是最大值本身。同一行有并列最大时，NumPy 返回沿该轴首先遇到的位置；这个规则不表示模型在数学上更偏好那个类别。对当前 X，`argmax(axis=1)` 返回 `[2,2]`，每个样本选中特征 2。保留轴得到 `(2,1)` 索引，再用 `take_along_axis` 从每行收集对应数值：

```python
index = X.argmax(axis=1, keepdims=True)
picked = np.take_along_axis(X, index, axis=1)
assert picked.tolist() == [[3],[6]]
```

`take_along_axis` 的 axis 必须明确。indices 在选取轴上提供要取的位置，其他轴按接口的相容规则匹配；索引需要整数且在范围内。它与把 `[2,2]` 直接写成 `X[index]` 不同：后者可能把它当作行索引，当前行数只有二，马上越界。每样本取不同类别分数时，收集轴应是类别轴，样本轴保持一一对应。

如果用 `take_along_axis(scores,target[:,None],axis=1)` 得到每个样本的目标类别分数，输出形状通常为 `(B,1)`。之后需要 `(B,)` 时，可以显式取 `[:,0]`。这条路径会出现在分类与损失代码中；理解 shape 和索引对象比记住某个神秘方括号写法更容易迁移。

## 拼接与堆叠：扩展已有轴或增加新轴

`concatenate` 沿已有轴拼接，其他轴长度必须相同。两份 `(2,3)` 的 X 沿轴 0 拼成 `(4,3)`，增加样本；沿轴 1 拼成 `(2,6)`，增加特征。axis 表示扩展哪一轴，结果轴数仍是二。

`stack` 要求各输入形状相同，再插入一条新轴。`np.stack([X,X],axis=0)` 得到 `(2,2,3)`，第一个 2 区分两份输入；`axis=1` 也得到 `(2,2,3)`，但新轴位于样本与特征之间，含义不同。形状长度相同仍可能隐藏新轴位置变化，因此应该用不全相等的测试尺寸或具体元素核对。

```python
assert np.concatenate([X,X], axis=0).shape == (4,3)
assert np.stack([X,X], axis=0).shape == (2,2,3)
```

不要先用 stack 再随意 reshape 来冒充拼接。它可能使元素顺序与希望的样本顺序不同。多个批次组成一个更大批时通常沿样本轴 concatenate；同样形状的多次观测需要保留“第几次”轴时通常 stack。真实数据管线还要明确空列表、尾部小批与不同长度序列的处理，不能只靠这一行函数吞掉形状差异。

反复在循环里 concatenate 不断增长的数组还可能反复复制已有内容。若所有小块已知，可以先收集到 Python 列表，最后一次拼接；若总形状已知，也可预分配并逐段写入。这里选择的是与已知任务匹配的原生操作，不需要额外封装一个泛化数组构建器。

## 随机与稳定 softmax：可复现和可计算是两份契约

`np.random.default_rng(seed)` 建立局部随机生成器，让这段实验的随机状态与其他代码分开。`rng.normal(size=(2,3))` 按指定形状生成正态样本；重新建立相同 seed 的生成器，并以相同顺序调用，能在同一运行条件下核对同样结果。使用同一个生成器再次调用会推进状态，并非每次重复上一份数组。

随机种子不是所有跨版本、跨硬件实验逐位一致的万能保证。可复现记录还应包含库版本、调用顺序、输入形状与算法边界。本章的核心数值用显式数组，随机部分只检验同一环境中的局部生成器行为，避免把某个生成器版本的输出写死在讲义里。

softmax 把每行未归一化分数（logits）转成正数且和为一的值。直接指数对很大分数会溢出。对每行先减去该行最大值 a，不改变指数比值，但使最大指数为一：

$$
a_i=\max_j X_{i,j},\qquad
P_{i,j}=\frac{\exp(X_{i,j}-a_i)}{\sum_k\exp(X_{i,k}-a_i)}.
$$

两个归约都沿类别或特征轴进行，并使用 keepdims 保留对齐位置：

```python
shifted = logits - logits.max(axis=-1, keepdims=True)
exp_values = np.exp(shifted)
probabilities = exp_values / exp_values.sum(axis=-1, keepdims=True)
```

输入 `[1000,1001,1002]` 会先变成 `[-2,-1,0]`，其输出约为 `[.0900,.2447,.6652]`。输入三项相等时，每项都是 $1/3$。给整行都加同一个常数不会改变结果，配套脚本用这一性质检查计算。有关概率解释与注意力作用回读 [P3](/principles/attention/)，这里关心的是尾轴计算和数值范围。

这份基础函数要求归约轴非空且输入为有限值。全为负无穷的屏蔽行会产生负无穷减负无穷，不能直接套公式；应由上层先定义空有效集合的行为。NumPy 不自动跟踪模型梯度，继续学习可求导张量时见 [F3 PyTorch 张量](/frameworks/torch-tensors/) 与 [F4 自动微分](/frameworks/autograd/)。

在分类代码中，还要区别“从各行取一个目标位置”和“把所有行合成一个分布”。若把 softmax 的最大值与指数和都沿 axis=0 计算，列上的和会为一，但每个样本的类别和未必为一。仅验证所有输出非负还不够，应根据模型契约核对每一行的和，以及每个样本是否只依赖自己的分数。把其中一行的分数改变，另一行的输出应保持不变，这是一个能发现错轴的实际检查。

同样，中心化时每一行的均值应接近零，矩阵乘时每个输出应对应明确的一组点积，收集时每个样本必须使用自己的索引。这些性质不会替代参考数值，但可以帮助发现恰好被某组重复数值掩盖的错误。小测试优先使用不同样本、不同特征值和非方形形状，让错误的轴对应无法凭巧合通过。

## 常见误区

| 操作 | 核对输入与输出的方式 |
| --- | --- |
| 逐元素运算 | 从尾轴配对，相等或长度一才兼容 |
| `sum / mean / var` | axis 指合并轴，keepdims 保留其长度一位置 |
| `* / @ / einsum` | 区分保留逐位置乘积与沿共同轴求和 |
| `where / clip` | 共同广播形状，检查分支运算及数值边界 |
| `argmax / take_along_axis` | 返回位置后，沿指定轴收集对应数值 |
| `concatenate / stack` | 前者扩展已有轴，后者添加新轴 |

- **Broadcast 按最前面的轴对齐。** 它从尾轴向前；每样本偏移通常需要 `(B,1)`，不是 `(B,)`。
- **Axis 表示保留哪个方向。** 对归约，它指定合并哪个轴，其他轴保留；axis=0 求样本之间的统计。
- **Keepdims 改变均值的定义。** 它只保留归约轴的位置，数值与分母不因此改变。
- **相同 shape 的乘法就是矩阵乘。** `*` 是逐元素乘，`@` 收缩矩阵轴，要检查保留的输出轴。
- **Where 只计算被选中的分支。** 分支表达式可能提前计算，需要避免非法运算时应明确控制计算位置。
- **随机种子让所有实验永远逐位相同。** 它控制指定生成器的状态，版本、算法与调用顺序仍需要记录。

## 练习与核对

<details>
<summary>(2,3) 的 X 加 (2,) 的偏移为什么失败？怎样表达每样本偏移？</summary>

尾轴 3 与 2 不兼容；把偏移显式变成 `(2,1)`，尾轴一扩展成三，样本轴二保持一致，才是每行加自己的偏移。若 X 是方阵，原表达式可能可运行但对错轴，因此测试应包含非方形输入。
</details>

<details>
<summary>[1,2,3] 的 var 在 ddof=0 与 ddof=1 下各是多少？</summary>

均值二，平方偏差和二。分母分别为三和二，结果为 $2/3$ 和 1。选择哪个取决于是在描述当前数据，还是按相应抽样假设估计总体方差；不能以数值更大作为更正确的理由。
</details>

<details>
<summary>einsum('bd,md->bmd') 为什么不是批线性层的输出？</summary>

输出仍保留 d，每个位置只存一项乘积。批线性输出还需要沿 d 把所有特征贡献相加，使用 `->bm` 或对中间结果最后一轴求和。形状从 `(B,m,d)` 变为 `(B,m)`。
</details>

<details>
<summary>每行的最大值位置是 [2,2]，为什么不能直接 X[[2,2]]？</summary>

那个表达式沿 X 的第一个轴取行，而索引的语义是最后一轴的列。应把索引保留成 `(2,1)` 并用 `take_along_axis(...,axis=1)`，明确每行各取自己的列位置。
</details>

<details>
<summary>两份 (2,3) 输入拼成 (4,3) 与堆成 (2,2,3)，分别多了什么？</summary>

前者沿已有样本轴增加位置，轴数不变。后者增加一条区分输入份数的新轴，原有样本与特征轴保留。新轴应该有明确含义，不能看到元素数量相同就随意互换。
</details>
