训练一个模型时，先得知道预测错了多少，再确定参数怎样改变，最后检查改变后的预测。数学路线围绕这一次计算展开：从数据和损失出发，把逐条计算写成矩阵运算，求出梯度，再训练一个两层网络。你只需具备 Python 基础；遇到数组轴、广播或自动求导的 API 障碍，可按需回读 [数组与框架路线](/frameworks/)。

## 阅读路线：概率怎样走到可训练的损失

<CourseMap track="math" />

先在路线图中选 M8，读它要解决的问题。若还不能写出 batch 线性层的形状，先读 M6；若还不能对一个参数求偏导，先读 M7。再选 M11，确认它是从 M6、M7 接入的分支，按需要阅读。

[M1 随机事件与条件概率](/math/events/) 从一次抽记录开始，说明事件、概率、联合概率、条件概率与独立性。[M2 贝叶斯与序列概率](/math/bayes/) 接着解决三个问题：怎样汇总不同来源、怎样根据结果反查来源、怎样给一串依赖历史的结果分配联合概率。

[M3 概率与统计](/math/probability/) 将随机结果映射为数值，用期望、方差与独立抽样解释 batch 均值的波动。[M4 信息量与熵](/math/information/) 则对负对数概率求期望，区分单次信息量、熵、条件熵、交叉熵与 KL。[M5 分布与预测损失](/math/distributions/) 把这套量落实到模型参数：logits 经 softmax 变成预测概率，最大似然对应经验 NLL，one-hot 交叉熵实现同一个目标。

这些章节按下面的顺序建立训练目标。M3 补充平均数与抽样波动的依据。进入 P2 前，还须通过 P1 把文本变成 token 输入。

流程中每一步都用到前面的计算能力。不要只看模型损失的一个数字：先说明它对哪些结果、按什么权重取了平均。

概率链式法则来自条件概率，不需要 token 独立；独立性是某些采样或模型的额外假设。贝叶斯用于反查条件方向，也不是链式法则的前提。数学路线用 $U,V$ 表示随机变量，对应其他资料常见的 $H(X)$、$H(X\mid Y)$；$X$ 在本课程还用于批输入矩阵。

有了损失，还要让同一组参数处理多条记录。[M6 向量与矩阵](/math/linear-algebra/) 从点积走到 batch 线性层，明确样本轴、特征轴和权重形状。[M7 微积分与梯度](/math/calculus/) 再问损失对参数的局部变化有多敏感、梯度下降一步能否降低损失。M6 解决“算什么”，M7 解决“往哪里改”。

实际网络有一整张权重矩阵，也有多层共享的中间结果。[M8 矩阵求导](/math/matrix-calculus/) 从一个权重元素推到整批参数梯度；[M9 反向传播](/math/backprop/) 说明多条计算路径如何在共享节点汇合。到 [M10 神经网络训练](/math/training/) 时，前向预测、交叉熵、反向求导和参数更新才闭合成一个训练循环。读完应能手算小网络的一步更新，并用代码核对梯度。

## 路线分支：下一步读什么

进入 [P1 文本、token 与嵌入](/principles/tokenization/) 前，至少要理解 M6 的矩阵与索引，以及 M10 中可训练参数如何更新。M10 的输入是实数向量；P1 从字符串出发，切出离散单位（token）并编号，再查可训练的 embedding 矩阵，把 ID 变成向量。这个桥梁建立后，[P2 下一 token 预测](/principles/language-modeling/) 才将 M2 的概率链式法则、M4 的条件交叉熵与 M5 的分类损失用于每一个预测位置。[P3 注意力](/principles/attention/) 还会用到 M6 的点积与 M5 的 softmax。

[M11 谱分解、低秩与数值稳定性](/math/spectral/) 是分支：完成 M6、M7 后，需要研究曲率、矩阵压缩或误差放大时再读。它连接 [T2 优化器](/training/optimization/) 与 [T6 LoRA](/training/lora/)，不是进入 P1 的门槛。模型位置编码中需要的旋转、复数与矩阵指数，会在 [模型原理路线](/principles/) 的相应章节引入。

## 公式约定：每个符号都有形状

一个记号首先要说明它代表什么对象、有什么轴。本路线把单样本向量写为列向量 $x\in\mathbb R^d$，一个 batch 的 $B$ 条样本按行放进 $X\in\mathbb R^{B\times d}$。若 $W\in\mathbb R^{m\times d}$、$b\in\mathbb R^m$，单样本线性层是 $z=Wx+b$；批量计算是 $Z=XW^\top+b$，形状为 $(B,m)$。代码中的 `nn.Linear(d, m)` 存储同样形状的权重，`X @ W.T + b` 沿 batch 轴广播偏置。

单样本损失记 $\ell_i$，batch 平均记 $L=B^{-1}\sum_i\ell_i$；梯度 $\nabla_W L$ 与 $W$ 同形状。概率、期望、导数和矩阵相乘的成立条件及更细的符号约定，都在首次用到它们的章节说明。

模型原理路线的注意力投影写作 $Q=XW_Q$，其中 $W_Q\in\mathbb R^{d\times d_h}$。因此 `q_proj.weight` 对应 $W_Q^\top$；与上面的 `nn.Linear` 权重只是转置布局不同。比较公式与代码时先对齐形状，再看变量名称。

## 核对方法：从一个数走到整个 batch

先手算一个样本、一个输出或一个参数的梯度，再看数组运算如何一次完成同样的计算。每章的配套脚本位于 `code/math/`，用固定例子和断言核对等式；断言通过不代表对所有输入都成立，推导中的条件仍须检查。

碰到公式时问三个问题：这个数来自目标分布还是抽样结果？矩阵的每条轴代表什么，平均除以多少？公式成立的条件在代码里是否仍满足？例如 M1 会说明条件事件必须有正概率，M3 会区分方差计算中的总体分母和样本校正分母，M8 会区分按 batch 求和与求平均。弄清这些区别，再进入下一章，才不需要背一张术语表。
