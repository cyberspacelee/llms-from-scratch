训练一个模型时，先得知道预测错了多少，再确定参数怎样改变，最后检查改变后的预测。数学路线围绕这一次计算展开：从数据和损失出发，把逐条计算写成矩阵运算，求出梯度，再训练一个两层网络。你只需具备 Python 基础；遇到数组轴、广播或自动求导的 API 障碍，可按需回读 [数组与框架路线](/frameworks/)。

## 阅读路线：七章怎样接成一次训练

<ChapterList track="math" />

[M1 概率与统计](/math/probability/) 先区分目标分布与抽到的一组记录（batch）：一个 batch 的平均损失为什么会波动？[M2 分布与信息量](/math/distributions/) 接着回答怎样把分类分数变成概率和损失。这里先把求导结果当作待解释的结论；导数规则在 M4 推导。

有了损失，还要让同一组参数处理多条记录。[M3 向量与矩阵](/math/linear-algebra/) 从点积走到 batch 线性层，明确样本轴、特征轴和权重形状。[M4 微积分与梯度](/math/calculus/) 再问损失对参数的局部变化有多敏感、梯度下降一步能否降低损失。M3 解决“算什么”，M4 解决“往哪里改”。

实际网络有一整张权重矩阵，也有多层共享的中间结果。[M5 矩阵求导](/math/matrix-calculus/) 从一个权重元素推到整批参数梯度；[M6 反向传播](/math/backprop/) 说明多条计算路径如何在共享节点汇合。到 [M7 神经网络训练](/math/training/) 时，前向预测、交叉熵、反向求导和参数更新才闭合成一个训练循环。读完应能手算小网络的一步更新，并用代码核对梯度。

## 路线分支：下一步读什么

进入 [P1 文本、token 与嵌入](/principles/tokenization/) 前，至少要理解 M3 的矩阵与索引，以及 M7 中可训练参数如何更新。M7 的输入是实数向量；P1 从字符串出发，切出离散单位（token）并编号，再查可训练的 embedding 矩阵，把 ID 变成向量。这个桥梁建立后，[P2 下一 token 预测](/principles/language-modeling/) 才将 M1 的条件概率和 M2 的分类损失用于序列中每一个预测位置。[P3 注意力](/principles/attention/) 还会用到 M3 的点积与 M2 的 softmax。

[M8 谱分解、低秩与数值稳定性](/math/spectral/) 是分支：完成 M3、M4 后，需要研究曲率、矩阵压缩或误差放大时再读。它连接 [T2 优化器](/training/optimization/) 与 [T6 LoRA](/training/lora/)，不是进入 P1 的门槛。模型位置编码中需要的旋转、复数与矩阵指数，会在 [模型原理路线](/principles/) 的相应章节引入。

## 公式约定：每个符号都有形状

一个记号首先要说明它代表什么对象、有什么轴。本路线把单样本向量写为列向量 $x\in\mathbb R^d$，一个 batch 的 $B$ 条样本按行放进 $X\in\mathbb R^{B\times d}$。若 $W\in\mathbb R^{m\times d}$、$b\in\mathbb R^m$，单样本线性层是 $z=Wx+b$；批量计算是 $Z=XW^\top+b$，形状为 $(B,m)$。代码中的 `nn.Linear(d, m)` 存储同样形状的权重，`X @ W.T + b` 沿 batch 轴广播偏置。

单样本损失记 $\ell_i$，batch 平均记 $L=B^{-1}\sum_i\ell_i$；梯度 $\nabla_W L$ 与 $W$ 同形状。概率、期望、导数和矩阵相乘的成立条件及更细的符号约定，都在首次用到它们的章节说明。

模型原理路线的注意力投影写作 $Q=XW_Q$，其中 $W_Q\in\mathbb R^{d\times d_h}$。因此 `q_proj.weight` 对应 $W_Q^\top$；与上面的 `nn.Linear` 权重只是转置布局不同。比较公式与代码时先对齐形状，再看变量名称。

跨路线沿用以下轴与数量记号；局部符号在出现时另行定义，不必预先记住。

| 记号 | 含义 |
| --- | --- |
| $B,T,T_{\mathrm{past}},T_{\mathrm{new}}$ | batch 大小、序列长度、历史长度、新增长度 |
| $d,d_h,d_{\mathrm{ff}}$ | 隐藏维度、每个注意力头的维度、前馈中间维度 |
| $n_{\mathrm{vocab}},n_q,n_{\mathrm{kv}},n_{\mathrm{layers}}$ | 词表大小、查询头数、KV 头数、层数 |
| $T_b,b_{\mathrm{elem}},n_{\mathrm{TP}}$ | 块内 token 数、每元素字节数、张量并行度 |
| $\beta,\omega_r,\tau$ | 位置频率底数、第 $r$ 个二维分块的角频率、采样温度 |

## 核对方法：从一个数走到整个 batch

先手算一个样本、一个输出或一个参数的梯度，再看数组运算如何一次完成同样的计算。每章的配套脚本位于 `code/math/`，用固定例子和断言核对等式；断言通过不代表对所有输入都成立，推导中的条件仍须检查。

碰到公式时问三个问题：这个数来自目标分布还是抽样结果？矩阵的每条轴代表什么，平均除以多少？公式成立的条件在代码里是否仍满足？例如 M1 会区分方差计算中的总体分母和样本校正分母；M5 会区分按 batch 求和与求平均。弄清这些区别，再进入下一章，才不需要背一张术语表。
