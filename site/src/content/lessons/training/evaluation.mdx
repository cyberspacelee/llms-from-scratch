模型 A 在两篇文章上的平均损失分别为 1 和 3，模型 B 的报告只有一个“平均损失”。如果第一篇有两个目标、第二篇有六个目标，把篇均值平均得到 2；按全部目标平均却得到 2.5。两个数字都能计算出来，但回答的是不同问题，不能在同一排行榜里混用。

评估首先定义被测对象和测量协议，之后才计算指标。先修是 [M1 概率](/math/probability/)、[M2 交叉熵](/math/distributions/) 与 [P9 生成](/principles/generation/)。可以使用 [T3](/training/pretraining/) 的小模型，也可以从一个版本固定的公开 checkpoint 开始，不要求先完成自己的训练。关键是固定模型、tokenizer、数据与输入条件。

## 评估契约：一个分数至少要带哪些条件

一个可复现结果至少记录：checkpoint 标识、tokenizer 与特殊 ID、数据版本和划分、输入模板、上下文长度、窗口步幅、目标选择规则、计算类型、模型模式、解码配置与评分实现。若模型处于服务端，还要记录接口日期和可能变化的后端版本。

两个模型都输出“准确率 80%”并不说明能力相同。一个可能使用选择题选项 logits，另一个自由生成文本；一个提供了示范，另一个没有；一个用多数投票，另一个只回答一次。测量边界不同，比较前要先说明差异，而不是用同一个指标名称掩盖它。

测试数据不参与训练并不足够。开发者反复看测试结果选择提示模板、解码温度和模型版本，也会对测试集适配。用验证集完成选择，再在保留测试集上执行预先确定的流程，更接近真实的独立评估；教学小实验没有保留测试集时，应称为验证观察。

公开 checkpoint 也有训练污染的不确定性。若无法核查完整预训练语料，应该明确无法排除，而不是用“测试文件没有传给微调脚本”就证明基座从未见过题目。

## NLL：按有效目标求和再统一除法

对第 $i$ 个有效目标 token $y_i$，模型在规定历史 $h_i$ 下给出概率 $p_i=P(y_i\mid h_i)$，负对数似然（negative log-likelihood，NLL）为 $\ell_i=-\ln p_i$。总指标是

$$
\overline\ell=\frac{\sum_i v_i\ell_i}{\sum_i v_i},
$$

其中 $v_i$ 表示目标是否参与评估。需要排除 padding、提示或重叠窗口的重复目标时，规则都进入 $v_i$。求和只包含有效项，分母是有效目标数；无有效目标必须明确报错或跳过，不应该输出零作为好成绩。

假设三次正确 token 概率为 $0.5,0.25,0.8$，NLL 分别约为 $0.693147,1.386294,0.223144$，均值为 $0.767528$。正确概率虽然平均为约 0.5167，但不能对概率先平均再取负对数，那会得到不同目标；对数刻画的是各次条件概率乘积的平均代价。

实际网络使用 logits 与稳定交叉熵接口。先做 softmax 再取对数可能把极小概率舍入为零；直接用 `log_softmax` 或交叉熵能减少这一问题。评价时通常不对 logits 应用采样温度，因为温度是生成策略的变换；若确实评估经温度校准后的分布，要单独声明。

## PPL：指数为什么放在平均之后

困惑度（perplexity，PPL）定义为 $\exp(\overline\ell)$。当使用自然对数时，它等于正确条件概率几何平均的倒数：

<KeyEq label="PPL 与几何平均">
$$
\operatorname{PPL}=\exp\left(-\frac1N\sum_i\ln p_i\right)
=\left(\prod_i\frac1{p_i}\right)^{1/N}.
$$
</KeyEq>

前面三个概率的乘积是 $0.1$，所以 PPL 为 $10^{1/3}\approx2.154435$。如果词表中每个 token 都均匀概率 $1/n_{\mathrm{vocab}}$，PPL 就是词表大小。这提供直观基线，但不意味着真实文本的 PPL 直接等于模型“犹豫的候选数量”。

不能先算每篇 PPL 再平均。指数是非线性函数，即使篇长相等，篇 PPL 的算术平均也通常不等于总体 PPL；篇长不同还需要先按目标数加权 NLL。保存损失总和与有效计数，可以可靠地合并批次和设备上的结果。

不同 tokenizer 将同一文本切成不同数量和类型的目标，token PPL 一般不能直接排名。可以在明确定义的相同原始文本上报告每字节或每字符的负对数概率，但需要确保两套编码的概率对应同一文本事件，并说明 BOS、EOS、规范化与不可逆编码规则。换分词器后只比较一个 PPL 数字容易误导。

## 窗口与步幅：长文档怎样只计算每个目标一次

有限上下文模型最多接收 $K$ 个输入 token。长文档不能一次全部送入，我们用滑动窗口提供上下文，同时保证目标不重复计分。窗口步幅 $s$ 表示每次新增多少评估目标，要求 $1\leq s\leq K$。

下标从零开始。每次选择新增目标区间 $[a,b)$，其中 $a\geq1$，$b=\min(a+s,N)$。输入区间为 $[u,b-1)$，其中 $u=\max(0,b-1-K)$。输入行 $j-1$ 预测目标 token $j$，只对 $j\in[a,b)$ 的输出计分；更早行仅提供上下文。

例如文档有 9 个 token，$K=4,s=2$。目标组依次为 `[1,3)`、`[3,5)`、`[5,7)`、`[7,9)`。第三组输入下标 `[2,6)`，提供 token 2 到 5，只评分目标 5、6；预测目标 3、4 的 logits 虽然也计算了，但不能再累计。最终恰好评分目标 1 到 8，各一次。

<Figure src="training/stride-windows.svg" alt="九个 token 分四组评估，每组输入最多四个 token，只对新增的两个目标计分">每一行是一次前向。蓝色是本次输入的 token，橙框是本次唯一计分的目标；输入行 j−1 预测目标 j，所以橙框比最后一个蓝格靠右一格。第 3、4 组的输入已被窗口 K 截断，更早的 token 不再可见。</Figure>

步幅不同会改变可见历史。$s=1$ 时，在长度允许范围内，每个目标都尽量有长前缀；$s=K$ 时，每组较早目标可见历史短得多，所以测量的条件概率不相同。窗口协议固定后才能公平比较；即使没有重复目标，也不能认为所有步幅会得到相同 NLL。

文档首 token 没有前驱，如果没有 BOS，本章不评分它。每篇文档单独滑窗，不把另一篇文档的末尾当作上下文。学习式位置编号是窗口局部从零开始，还是保留绝对位置，还需要遵循模型支持范围；不同位置策略也属于协议，而不是无关实现细节。

## 有限上下文与缓存：速度改变不能偷偷改变条件

使用 [P10](/principles/kv-cache/) 的缓存可以避免重复计算历史，但缓存总长度、窗口淘汰和绝对位置必须与评估定义一致。如果保留整篇历史，缓存评估事实上使用了比滑窗更长的上下文，不能拿速度更快解释分数差异。

对学习式位置表，简单删除最旧缓存但不重算剩余隐藏状态，通常不同于把保留 token 从零位置重新运行。剩余隐藏状态曾经看过已淘汰历史，位置也可能不同。这是条件分布问题，不只是数组长度问题。教学评估先用显式窗口重算，建立容易审计的参照。

验证时关闭 dropout，固定批处理条件；缓存与重算的浮点运算顺序仍可能不同，所以对比 logits 应给出数值容差。若微小误差改变采样分支，最终文本可以差很多，不能只比较字符串判断缓存是否正确。

## 任务评分：怎样从条件概率走到行为测量

NLL 测量文本预测，任务指标测量按规定输入条件完成任务的行为。两者相关但不等价。微型复制任务可以输入 `复制最后两个字符：ab`，期待 `ab`；格式任务可以要求输出固定键值结构；分类任务可以固定选项及答案匹配规则。

评分前明确哪些差异允许。例如精确匹配（exact match）是否忽略首尾空白、大小写和标点？JSON 任务是比较原始字符串，还是解析后核对字段？合法结构但值错误应分别记录，避免把格式成功等同于任务成功。答案解析失败不能任意重试直到得到理想输出。

多选题可以比较完整选项的序列概率，而不能总是假定每个选项只占一个 token。长度不同的选项还要明确使用总 log-probability 还是长度归一化分数，因为两者代表不同判定规则。自由回答则要固定最大生成 token 数、停止条件、温度与种子。

小型位置专项可保持内容相同，只改变需要复制的片段到提示末尾的距离。短距离先建立基线，再增加干扰项与距离；只有用规定长度和多组样本测量后，才可以讨论长距离退化。对复杂推理、代码或事实任务，一个示例正确远不足以给出能力结论。

## 样本量与不确定性：8/10 不是精确的 80%

假设每题独立、相同成功概率，$n$ 道题中成功 $k$ 道，点估计是 $\widehat p=k/n$。小样本下，直接使用 $\widehat p\pm1.96\sqrt{\widehat p(1-\widehat p)/n}$ 可能在边界处失真，甚至跑到 $[0,1]$ 外。脚本用 Wilson 区间给出一个更稳妥的二项比例例子。

令 $z=1.96$，Wilson 区间中心与半径为

$$
c=\frac{\widehat p+z^2/(2n)}{1+z^2/n},\qquad
r=\frac{z\sqrt{\widehat p(1-\widehat p)/n+z^2/(4n^2)}}{1+z^2/n}.
$$

$8/10$ 的近似 95% 区间为 $[0.490,0.943]$，相当宽。这不是说真概率有 95% 的随机机会落在这次区间内，而是频率学派重复构造程序的覆盖率解释。数据相关、同题多次采样或同一模板生成近似题时，独立假设不成立，需要按适当单位估计不确定性。

比较模型时，同一组题上的成败是配对观察。保留逐题结果比只保存两个均值更有用，可以检查哪些题发生变化；抽样或 bootstrap 也应按题、文档等独立单位进行。单次训练种子和单次解码种子测量的是一个实现，不足以估计训练与采样的全部方差。

### 配对 bootstrap 怎样保留同一题的关系

设两个模型在 n 道相同题上分别得分 $a_i,b_i$，先计算 $d_i=b_i-a_i$。每次从题索引中有放回抽取 n 个索引，再对对应的 d 求平均；重复两千次，取 2.5% 与 97.5% 分位数作为百分位 bootstrap 区间。同一抽样索引同时作用于两个模型，保留“这道题本来很难”的关联。

`paired_bootstrap` 固定 seed 并返回差值均值、区间与重复数。两个模型逐题相同，所有抽样差值都为零；第二个模型逐题加一，所有差值都为一。脚本用这两种结构性质核对，再给一组非平凡成败样例。bootstrap 仍依赖独立抽样单位，小样本或离散得分的覆盖可能不理想；同一文档的多个窗口应按文档分组，不能把它们当独立题扩大样本量。

T3 的文本程序保存逐窗口目标数和 NLL，便于定位差异；正式报告还应保留文档 ID、模型配置、tokenizer 指纹、预算、seed 与评估条件。相同配置和种子只能保证复现当前实验，不能替代多种子的不确定性评估。

## 受控实验：一次改变一个可归因因素

若要测试 LoRA 秩，将基座、目标模块、训练数据、有效 token 预算、优化器与评估固定，只改变秩并记录可训练参数量。若要测试 GQA，固定模型主干和数据协议，说明 KV 头数改动的参数与缓存差异。每个改动都可能改变资源预算，所以“同样步数”未必是“同样算力”。

消融（ablation）通过移除或替换一个组成部分，观察结果变化。结果只能支持在当前组合和预算下的影响，不能证明该部件在任何模型中都必需。假设组合 A+B 改善，而单独 A 或 B 未改善，可能存在交互效应；不能简单把总收益平均归给两者。

预先写下主指标、验证频率和选择规则，可以减少观察后挑结论。记录失败配置与全部种子，避免只展示最好的一条曲线。报告可以很短，但必须能回答：比较了什么，固定了什么，数据多大，差异多大，限制是什么。

### 完整模型消融怎样声明固定条件

`ablation.py` 对 [P11](/principles/complete-transformer/) 分别采用一个和两个 KV 头，固定训练/验证文档、tokenizer、二十四次更新、窗口顺序与实际目标预算；运行两个 seed。形状未改变的分支从同一个参考初始化复制权重，避免因为 K/V 投影大小改变随机数消费而让整个 FFN 初始值也变掉。

程序分别保存每篇验证文档的 NLL，按文档身份做配对差值和 bootstrap，不把同文档的短窗口视为独立样本。改变 KV 头会改变参数量与运算量，因此这个协议是“相同目标预算”，不是“相同 FLOP”。每个 seed 的改善或退化都原样输出，不断言某配置必须胜出；只有两篇验证文本，区间仅用于检查统计程序，不能报告显著性结论。

## 常见误区

PPL 越低不表示每种任务都更强；tokenizer 不同不能直接比较 token PPL；滑窗重叠不等于目标可以重复评分。采样产生的不同答案可能来自解码配置，而非模型更新。看到验证集上的提升，应报告该协议下的提升，避免扩大成没有测量过的通用能力结论。

## 练习与核对

<details>
<summary>两篇文档有 2 和 6 个目标，NLL 均值为 1 和 3。总体 PPL 是多少？</summary>

总体 NLL 是 $(2+18)/8=2.5$，所以 PPL 为 $e^{2.5}\approx12.1825$。先平均篇 NLL 得到 2 会错用权重；先平均两篇 PPL 也不是总体 PPL。

</details>

<details>
<summary>滑动窗口重复读取一个 token，是否就是评估泄漏？</summary>

不是。重复读取历史作为上下文是窗口评估的正常做法；需要防止的是同一个目标在总损失中多次计数。训练和测试数据混入才属于另一类污染，两种边界应分别核查。

</details>

<details>
<summary>模型 A 得 8/10，模型 B 得 9/10，能否宣称 B 明显更好？</summary>

不能只凭两个点估计。查看是否同一组题、逐题差异、样本相关性和随机性，并扩大样本或报告适当不确定性。即使观测 B 较高，也应把结论限制为当前样本与协议。

</details>
