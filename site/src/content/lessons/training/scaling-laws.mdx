有一笔固定训练预算，选择模型大一倍、训练 token 少一半，还是保持小模型、读更多数据？两种方案的粗略乘积 ND 相同，验证损失未必相同。问题必须同时考虑模型容量与数据，而不是只问参数越大是不是越好。

[T3](/training/pretraining/) 已说明粗略计算账 $C\approx6ND$；[T4](/training/evaluation/) 已定义可信评估。本章把它们变成可检查的拟合问题。数学先修是 [M1 均值与不确定性](/math/probability/)、[M4 导数](/math/calculus/)；线性代数与数值敏感性可回读 [M8](/math/spectral/)。本章的规律是经验模型，不是所有 Transformer 都必须服从的定理。

## 幂律与下限：直线在哪个坐标里成立

设 x 是数据量，损失写成 $L(x)=E+A/x^\alpha$，其中 $A>0,\alpha>0$，E 是假设的极限损失。取对数得到

$$
\log(L-E)=\log A-\alpha\log x.
$$

因此直线发生在 $\log x$ 与 $\log(L-E)$ 之间。若 E 非零，直接画 $\log L$ 对 $\log x$ 会在大 x 处弯曲。比如 $E=1,A=4,\alpha=1$，x 为 1、2、4 时，L 为 5、3、2；减去下限后才是 4、2、1 的规则减半。

对数坐标的斜率 −α 表示 x 翻倍时，可约损失乘 $2^{-\alpha}$。这比“多训练一倍降低多少 NLL”更稳定地表达比例，但拟合对数残差与拟合原损失残差不是同一目标：前者对小可约损失赋予更大相对权重。

E 也不是已知的自然常数。它依赖任务、tokenizer、评估数据与上下文条件。用十几个高噪声点同时拟合 E 与指数，可能出现不同参数给出相似曲线；必须检查残差和未用于拟合的点，不能只读训练拟合误差。

## 联合损失：模型和数据怎样各自留下误差

一种常用参数化形式是

$$
L(N,D)=E+\frac{A}{N^\alpha}+\frac{B}{D^\beta}.
$$

N 为声明口径下的参数数，D 为训练目标事件数，E 为不可约项。模型项与数据项相加是建模假设：真实训练还受学习率、架构、重复语料、上下文、优化完成程度影响。拟合时这些条件必须固定或明确纳入设计。

为了看清量级，取教学真值 $E=0.5,A=4,B=2,\alpha=0.6,\beta=0.4$，N、D 使用声明的教学单位。模型扩四倍时，模型项乘 $4^{-0.6}\approx0.435$；数据扩四倍时，数据项乘 $4^{-0.4}\approx0.574$。这两个指数不相等，因此最优预算分配不会固定为 N/D 某个通用常数。

若把 N 单位从一个参数改成一千参数，A 必须一起改变。例如 $N=1000N'$ 时 $A/N^\alpha=(A/1000^\alpha)/(N')^\alpha$。指数不受这种单位转换影响，系数受影响；把不同单位的系数直接粘到预算公式中，会产生错误数量级。

## 拟合：指数固定时，剩下的是线性最小二乘

给定 α、β，第 i 个测量的设计行是 $[1,N_i^{-\alpha},D_i^{-\beta}]$，未知向量是 $[E,A,B]^\top$。将所有行堆成 X，损失堆成 y，最小化

$$
\|Xc-y\|_2^2,\qquad c=(E,A,B)^\top.
$$

脚本调用 `np.linalg.lstsq`，不显式求 $(X^\top X)^{-1}$。后者多写了一次求逆，而且会平方条件数；[M8](/math/spectral/) 已解释为什么数值敏感性不是单看最终公式。

指数未知时，教学实现先在 α、β 的有限网格上搜索，再在最佳位置附近细化两次。每个候选指数都用库函数解线性系数，仅保留 E 非负、A/B 正的候选。初始指数范围为 0.2 到 1.2，之后局部细化；范围是教学选择，网格边界附近的最优点应提示继续扩大搜索，不能声称找到无约束全局最优。

至少需要 N、D 都变化。只在同一个 N 上增加 D 时，E 与 $A/N^\alpha$ 无法分开；只沿单条固定 ND 曲线也容易耦合两项。脚本拒绝 N 或 D 不变的设计，用四种 N 与四种 D 的笛卡尔积核对合成真值。观测数多于未知数只是起点，不保证参数可辨识。

```mermaid
flowchart LR
  G[声明 N/D 网格与评估协议] --> M[训练并测验证损失]
  M --> F[候选指数 / 线性系数拟合]
  F --> R[看残差与边界]
  R --> H[未参与拟合的点]
  H --> B[预算分配]
  B --> V[目标预算上的实际验证]
```

最后一个实际验证步骤不能省略。曲线在小尺度拟合好，只说明该范围内可以预测；外推到更大模型时可能进入新的优化或数据限制。

## Isoflop：把两变量问题压成一个变量

固定 $C\approx6ND$，令 $D=C/(6N)$，代入联合损失：

$$
L_C(N)=E+AN^{-\alpha}+B\left(\frac{6N}{C}\right)^\beta.
$$

第一项随 N 增大下降，第二项随 N 增大上升，因为同预算下数据减少。这解释 isoflop 曲线为何可能形成一个最低点。对 N 求导，令零，得到

$$
-\alpha AN^{-\alpha-1}+\beta B(6/C)^\beta N^{\beta-1}=0.
$$

整理后

$$
N_*=\left[\frac{\alpha A}{\beta B}\left(\frac C6\right)^\beta\right]^{1/(\alpha+\beta)},
\qquad D_*=\frac C{6N_*}.
$$

两项均正、指数正时，这是正 N 域中的唯一最低点。若 N 或 D 有可行上下限，必须再裁到可行边界并比较端点；实际层数、宽度和头数只能离散取值，应选附近可实现配置并实测，而不是训练“隐藏维 23.7”。

## 预算放大：平方根规律需要什么条件

由上式可见 $N_*\propto C^{\beta/(\alpha+\beta)}$，$D_*\propto C^{\alpha/(\alpha+\beta)}$。只有 α=β 时，两者才都与 $\sqrt C$ 成正比。取本章 α=0.6、β=0.4，预算四倍时 N 乘 $4^{0.4}\approx1.741$，D 乘 $4^{0.6}\approx2.297$，乘积正好四倍。

Chinchilla 的实验支持在其研究设置下模型和数据近似等速缩放。其著名配置约 70B 参数、1.4T token，不能据此把“每参数 20 token”当作所有数据集、推理需求和训练预算的硬规则。若长期服务推理成本也要计入，较小模型多训练可能更合适，训练最优与总成本最优是不同目标。

计算账也必须与模型对齐。6ND 是粗略估计，忽略注意力与部分非矩阵运算，参数口径还可能包含查表项。长上下文训练的注意力项很重要；[T3](/training/pretraining/) 已给真实 FLOP 计数。在本章 CPU pilot 中，字段明确叫 `approximate_flop`，不是硬件实测计算量或执行时间。

## 重复数据：见过的目标不等于独立语料

一百个唯一 token 重复十次，训练目标事件是约一千次，唯一语料仍约一百。D 在训练计算账中数执行过多少事件；数据质量与覆盖分析还要另记唯一数据量、来源重复率与 epoch。不能通过重复同一份数据把计算曲线标成“拥有十倍独立数据”。

当某来源只有少量高质量文本，增加其混合权重可能使它被重复几十次。初期收益与长预算下的最优混合可能不同。[T8](/training/data-engineering/) 会计算 $p_s D/D_s$ 的来源重复次数。小尺度选择混合时，应模拟目标尺度的重复压力，或至少明确外推假设。

## 两个实验：算法真值与真实测量分别看

默认 `python code/training/scaling.py` 用合成真值核对五参数恢复、未参与拟合的点、固定预算最优点和不同指数的缩放。它的低误差说明算法能恢复这种形式的数据，不说明自然文本真的服从该形式。

真实测量运行：

```sh
python code/training/scaling.py --measure --output scaling-pilot.json
```

它使用 [P11](/principles/complete-transformer/) 的同一个模型与 T3 自编语料，宽度 16、24、32，分别在第 8、16、32 步记录验证 NLL。固定 tokenizer、验证 63 个目标，参数数分别为 9072、15912、24288。D 累计实际监督目标，分别为 110、207、414，不是简单拿步数乘一个假设 batch size。

这九个测量点是小规模 pilot，数据重复、单一随机种子、短训练，不能拟合后宣称复现大型模型幂律。脚本将其输出为独立记录，不强行把真实曲线拟合成理想合成形式。后续研究可扩大独立语料、重复种子、固定预算网格、训练到合适学习率终点，再比较 held-out 残差。

## 常见误区

- 忘记损失下限 E，就把 log-log 图拟成直线。
- 用一条轨迹的相关点当作大量独立实验，低估不确定性。
- 强制设 α=β，随后把平方根规律解释成推导结论。
- 把 token 数、唯一数据量、有效目标事件和输入元素数量混用。
- 用估计 FLOP 或 CPU 小样本声称 GPU 吞吐和大模型质量。

## 练习与核对

<details>
<summary>α=β=0.5、A=2、B=8 时，最优 N 与 D 是否相等？</summary>

导数条件给 $\alpha A/N^\alpha=\beta B/D^\beta$，因此 $2/\sqrt N=8/\sqrt D$，得到 D=16N。指数相同只保证它们随预算等速增长，不保证数量相等；系数与单位决定比例。

</details>

<details>
<summary>为何要核对未参与拟合的点，而不只打印 MSE？</summary>

拟合参数是为减少已有点的误差而选择的。未参与拟合的点检验预测能力，特别是不同 N/D 比例和范围边缘。若只核对已拟合数据，错误假设也可能靠增加自由度获得漂亮误差。

</details>
