模型原理路线已经说明，给定一段 token，Decoder 怎样输出下一 token 的分布。训练路线回答接下来的问题：这些分布来自什么数据，怎样更新，怎样判断改善，以及怎样让同一个基座适配对话和特定任务。

## 九章：训练闭环、适配与放大实验

<ChapterList track="training" />

T1 把文档变成带三类遮罩的样本，T2 决定参数从什么尺度出发、怎样更新、训练内存由什么构成，T3 把两者接成一次可中断恢复的完整训练，并估算放大后的计算预算。T4 规定怎样测量改善，之后 T5、T6 才改变训练目标与可训练参数：T5 让模型学会对话格式并推广到蒸馏，T6 只训练低秩增量。

[T7](/training/scaling-laws/) 拟合联合缩放与计算预算，[T8](/training/data-engineering/) 补原始数据、过滤、近重复和混合，[T9](/training/distributed-training/) 用两个真实 Gloo 进程核对全局目标与更新。它们是 T3/T4 之后可选读的规模分支，不要求先读完 LoRA 才能学习 DDP；T3 的现代文本实验先完成 [P11](/principles/complete-transformer/)。

如果已经有公开 checkpoint，可以从 [T4 模型评估](/training/evaluation/) 开始，再回到数据和训练实现。需要微调时，先明确 [T5](/training/instruction-tuning/) 中哪些目标 token 参与损失，再用 [T6](/training/lora/) 决定更新哪些参数。

## 先修与记号

先完成 [P1 文本、token 与嵌入](/principles/tokenization/)、[P2 下一 token 预测](/principles/language-modeling/) 和 [P4 一个完整 Decoder](/principles/decoder/)。优化器推导还会用到 [M6 反向传播](/math/backprop/) 与 [M7 神经网络训练](/math/training/)；张量、求导边界与训练状态的 API 契约在 [F4](/frameworks/autograd/) 与 [F6](/frameworks/data-and-training/)。现代块、生成和缓存分别回读 [P8](/principles/modern-decoder/)、[P9](/principles/generation/) 与 [P10](/principles/kv-cache/)。

各章使用同一套训练约定：先按文档划分，再构造样本；损失按有效目标 token 求平均，记 $N_{\mathrm{valid}}$；参数与优化器状态分开；每个指标都有数据、模板和上下文边界。学习率记 $\eta$，权重衰减系数记 $\lambda$，LoRA 的秩记 $r$；其余维度沿用 [数学导读的跨路线记号](/math/#公式约定每个符号都有形状)。

## 怎样核对

每章配一个只需 CPU 的脚本，固定随机种子，用 float64 与 assert 核对推导：

```sh
python code/training/data.py
python code/training/optimization.py
python code/training/pretraining.py
python code/training/evaluation.py
python code/training/instruction_tuning.py
python code/training/lora.py
python code/training/text_pretraining.py
python code/training/ablation.py
python code/training/scaling.py
python code/training/data_engineering.py
python code/training/distributed_training.py
```

脚本验证的是算法与实验流程：遮罩与分母、AdamW 手算、检查点前后的梯度、恢复后逐位相同的训练轨迹、FLOP 计数、窗口不重复计分、蒸馏梯度与 LoRA 合并。CPU 小模型不能据此推断大模型的能力或 GPU 吞吐；这些成本在 [推理系统](/systems/) 中按字节与秒重新记账。
