以 [完整Decoder](/principles/complete-transformer/) 为基线：每个token经过前馈层，注意力读取可见历史。新的结构应回答具体问题：改的是哪个算子，哪些信息仍保存，输出与哪个参考一致，省下的资源是否转移到别处。

## 按问题进入

| 要解释的问题 | 入口 | 继续核对 |
| --- | --- | --- |
| 每个token只调用部分前馈参数 | [MoE](/advanced/moe/) | 原token行、路由权重、专家容量和通信 |
| 压缩每个位置的注意力状态 | [MLA](/advanced/mla/) | naive/absorbed输出、梯度与位置分支 |
| 更远的位置与更窄的可见窗口 | [长上下文](/advanced/long-context/) | 同频率、同可见集合、远距离任务 |
| 固定状态处理历史 | [状态空间](/advanced/state-space/) → [混合层](/advanced/hybrid-attention/) | 递归终态、卷积历史与逐位置KV分别计账 |
| 只读取选择出的历史位置 | [稀疏注意力](/advanced/sparse-attention/) | 选择成本、因果性与同集合dense参考 |
| 视觉特征接入语言序列 | [视觉语言模型](/advanced/multimodal/) | patch、slot、目标行与视觉梯度 |

这些分支各有必要先修。MoE改变FFN调用，MLA改变历史表示；递归汇总历史，稀疏注意力保留逐位置历史再选择读取。按自己的计算问题进入，不必依次读完所有架构。

## 研究机制的入口

下面五章都是选读，各从一个小张量问题出发。它们连接统一包中的机制实验，保留每项真实先修；其中独立函数不自动成为标准 `TransformerBlock` 的组成部分。

| 研究问题 | 教材章节 | 可运行实验 |
| --- | --- | --- |
| 多加一级预测怎样对齐输入与未来标签 | [A8 多 token 预测](/advanced/multi-token-prediction/) | `chapter --chapter 14` |
| 旧块摘要怎样与精确近期 token 拼接 | [A9 序列压缩](/advanced/sequence-compression/) | `chapter --chapter 19` |
| 多条残差通道怎样混合并接收分支写入 | [A10 多残差流](/advanced/residual-streams/) | `chapter --chapter 22` |
| 局部 token 身份怎样查表并受上下文调节 | [A11 条件记忆](/advanced/conditional-memory/) | `chapter --chapter 23` |
| 多个上层查询怎样复用因果历史 | [A12 跨层共享 K/V](/advanced/shared-kv/) | `chapter --chapter 24` |

在仓库根目录用 `uv run llms-from-scratch` 加表中的子命令运行。文章里的 A 编号是学习顺序，实验编号是稳定的机制入口，两者无需相等。先核对形状、因果候选、同定义的参考输出和梯度，再讨论具体模型的工程策略；这些 CPU 小张量检查不能推断生产性能。

训练回复行为另走 [后训练路线](/post-training/)：DPO、RLVR和蒸馏改变监督信号。异构状态的安全前缀复用与回滚见 [混合缓存](/systems/hybrid-cache/)，在那里区分模型公式与运行期所有权。
