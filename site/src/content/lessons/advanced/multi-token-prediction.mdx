[P2 下一 token 预测](/principles/language-modeling/) 在位置 t 监督下一项。现在给一段六 token 训练序列 `[1,2,3,4,5,6]`，除主模型目标外再增加两级预测。我们要算清每一级消费哪个 token、监督哪个 token，以及序列末尾为何越来越短。这个研究分支使用统一模型已有的 MTP 模块，普通生成仍走原来的下一 token head。

“多 token 预测”可以指共享主干上多个独立 head，也可以指依次连接的额外模块。本章实现采用后一种**顺序 MTP**。独立多头与顺序模块是不同结构，不能只按目标数量认作同一个算法。[原始多 head 研究](https://arxiv.org/abs/2404.19737) 与 [DeepSeek-V3 的顺序方案](https://arxiv.org/abs/2412.19437) 可作为这一区别的来源。

## 六个 ID：先把主目标和额外目标排成表

设未移位 token 张量 $U$ 为 $(B,T)=(1,6)$，主模型隐藏状态 $H^{(0)}$ 为 $(1,6,D)$，词表大小为 V。主 head 第 t 行预测 $U_{t+1}$，最后一行没有目标，因此主损失计 5 项。

额外深度 r 从 1 开始：它使用上一深度在锚点 t 的状态，并显式读入真实 token $U_{t+r}$ 的 embedding，预测 $U_{t+r+1}$。为了避免把“深度”和“目标偏移”混淆，记偏移 $\delta=r+1$。

| 分支 | 在锚点 t 的新输入 | 监督目标 | 本例计分标签 | logits 长度 |
| --- | --- | --- | --- | --- |
| 主 NTP | 主模型前缀状态 | $U_{t+1}$ | `[2,3,4,5,6]` | 5 |
| MTP 深度 1 | 上一状态与 $E[U_{t+1}]$ | $U_{t+2}$ | `[3,4,5,6]` | 4 |
| MTP 深度 2 | 上一状态与 $E[U_{t+2}]$ | $U_{t+3}$ | `[4,5,6]` | 3 |

例如锚点 t=0：主 head 用 ID 1 的前缀状态预测 2；第一额外深度再消费真实 2，预测 3；第二额外深度消费真实 3，预测 4。它没有让预测 3 的单元读到真实 3。也不能将第二额外预测解释成“只给 ID 1 就直接预测 4”：训练中已经给它真实中间 token，条件历史不同。

## 特征拼接：时间轴为什么每级只短一格

对深度 r，先截去上一状态末行，再取真实 token 的偏移切片。两者都长 $T-r$，各自 RMSNorm 后沿**特征轴**拼接：

$$
G^{(r)}_t=\operatorname{concat}\!\left(
\operatorname{RMSNorm}(H^{(r-1)}_t),
\operatorname{RMSNorm}(E[U_{t+r}])\right)W_r,
\quad W_r\in\mathbb R^{2D\times D}.
$$

拼接形状 $(B,T-r,2D)$，投影回 $(B,T-r,D)$，再经一个独立 causal block 得到 $H^{(r)}$。PyTorch 存储 `Linear(2D,D).weight` 为 $(D,2D)$，是式中数学矩阵的转置。

该 block 的行 t 可读取额外序列的行 $0\ldots t$；那些行最新消费的 token 最多是 $U_{t+r}$，不会触及目标 $U_{t+r+1}$。输出 norm 与共享 head 后再截掉末行，logits 是 $(B,T-r-1,V)$，对齐 `tokens[:, r+1:]`。若误沿时间轴拼接，两条输入不仅长度改变，位置身份与 causal 边界也会改变。

各深度的 norm、投影与 block 参数独立，词表 embedding 和输出 head 从父模型传入。共享 head 不等于共享额外 block；新增参数和训练计算来自每一级的投影、归一化和块。

## Loss mask：不能跨越一个无效中间位置

额外预测链从 t 走到 $t+\delta$。若 token 有有效标记 $m_t$，只在整段链连续有效时计分：

$$
a^{(\delta)}_t=\prod_{i=0}^{\delta}m_{t+i}.
$$

本例没有 PAD，所有标记为 1。若改成 `[1,2,PAD,4,5,6]`，从 1 走到第三位置的链包含 PAD，应排除；不能只检查目标 ID 是否有效，就把两段互不连续文本当作同一因果链。这里的 valid 表示 token 连续有效，SFT 中“这个回答位置是否计分”的 loss mask 有另一种语义，不应直接套用。

每个深度先按本深度有效目标数计算平均 NLL，再平均额外深度的损失。忽略独立的 MoE 辅助项，联合目标为

$$
L=L_{\mathrm{NTP}}+\lambda\frac{1}{K}\sum_{r=1}^{K}L_{\mathrm{MTP},r}.
$$

若主损失 0.6，两额外深度分别 0.8、1.2，$\lambda=0.3$，总损失为 $0.6+0.3\times(0.8+1.2)/2=0.9$。这是按深度平均，不是将 5+4+3 个位置一次求平均；两者权重不同。

普通 `Transformer.generate` 不调用训练中的未来真值分支。将 MTP 用于草稿生成，需要先用已生成或拟议 token 替代真实中间输入，再制定验证、接受与回退协议；这属于 [投机解码](/systems/speculative-decoding/) 的问题。本章的标签和梯度断言不构成速度提升或生成质量证据。

## 练习与核对

<details>
<summary>序列只有 `[1,2,3,4,5]`，两级额外预测的标签和形状是什么？</summary>

深度 1 的目标是 `[3,4,5]`，logits 为 $(1,3,V)$；深度 2 的目标是 `[4,5]`，logits 为 $(1,2,V)$。每多一深度，未来标签可用范围短一格；不能通过补一个虚构 EOS 来维持原长度。

</details>

<details>
<summary>深度 1 在 t=0 预测 ID 3，却给融合层输入 ID 3 的 embedding，会发生什么？</summary>

输入包含本次答案，造成标签泄漏。正确输入应是 ID 2 的 embedding；预测 3 仍是一个未知分类目标。loss 下降和形状正确都无法证明因果性。

</details>

<details>
<summary>主损失 0.6，额外损失 0.8、1.2，λ=0。哪些梯度路径仍来自目标？</summary>

总目标只保留主 NTP 及另行启用的辅助项。两个额外分支的语言预测项没有权重，因此不再通过这两项贡献梯度；共享 embedding/head 仍可从主目标更新。存在共享参数不意味着每个额外 block 一定被主目标训练。

</details>
