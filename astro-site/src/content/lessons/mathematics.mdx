数学在深度学习（DL）里承担四项工作：概率论描述数据与预测的不确定性；线性代数组织表示和计算；微积分衡量参数变化的影响；神经网络把这些工具连成可训练的函数。本系列从可手算的小例子开始，不要求先学过深度学习。

关于旋转位置编码的推导集中在 [08 旋转与位置编码](../../lessons/math-08)。如果只为阅读 RoPE 做准备，可以先读第 03 章再跳到第 08 章；要理解训练，则按下表读到第 07 章。

## 02 · 术语约定：先说明讨论的对象

| 术语 | 本系列中的含义 | 容易混淆的概念 |
| --- | --- | --- |
| 样本均值（sample mean） | 一组观测值的算术平均 | 期望按概率分布加权，不是一组观测本身 |
| 总体均值 / 期望（expectation） | 分布存在期望时，两个名称指同一个量 | 不一定是最可能的结果，也不一定能实际取到 |
| 方差 / 标准差 | 平方偏差的期望 / 方差的平方根 | 标准差与原变量同单位，方差是单位的平方 |
| 正态分布（normal / Gaussian） | 参数为均值与方差的连续分布 | 密度曲线的高度不是某个点的概率 |
| 导数 / 偏导数 | 一元变化率 / 固定其他变量的变化率 | 偏导是一个分量，梯度收集全部分量 |
| 梯度（gradient） | 标量函数对其输入或参数的导数集合 | 雅可比矩阵描述向量函数全部输出的偏导 |
| 小批量（mini-batch）/ 批大小 | 一次计算使用的一组样本 / 这组样本的数量 $B$ | 批大小与特征数 $d$ 是不同的轴 |
| 未归一化分数（logits） | 分类输出层给出的实数分数 | softmax 将其变成概率，交叉熵衡量预测与标签的差异 |
| 独热编码（one-hot） | 正确类别位置为 1，其他位置为 0 的表示 | 类别索引是整数，独热标签是向量 |
| 自动微分（automatic differentiation） | 按实际计算图组合局部导数规则 | 与有限差分、符号代数求导不同 |
| 前向传播（forward pass） | 从输入逐层计算预测与损失 | 与时间序列的“方向”没有必然关系 |
| 反向传播（backpropagation） | 从损失出发，按链式法则累加梯度 | 优化器随后用梯度更新参数，这是另一步 |
| 归一化 / 标准化 | 必须说明具体公式 | 除以范数、减均值除标准差、softmax 不是同一运算 |

“均值”这个词本身并不排斥“期望”：说正态分布的均值，指的就是它的期望；说这 32 个观测的均值，指的是样本均值。后文明确区分总体量与样本统计量，避免把两个层次的数混为一谈。

归一化是较宽泛的名称，本系列尽量直接写运算：向量除以自身范数叫单位化，减均值再除标准差叫标准化，softmax 叫按类别进行概率归一化。遇到框架中的 BatchNorm、LayerNorm，会说明实际在哪个轴上统计，而不是只凭名称判断。

## 03 · 公式约定：每个符号都有形状

标量用小写，向量用小写并默认是列向量，矩阵用大写。随机变量优先写作 $U,V$，以免与批输入矩阵 $X$ 混淆。转置写作 $\top$，矩阵乘法写作相邻乘积，逐元素乘法写作 $\odot$，对数默认自然对数。

| 符号 | 形状 / 含义 | 代码对应 |
| --- | --- | --- |
| $x$ | $d$ 维列向量，单个样本 | 显式列为 `(d, 1)`；一维存储为 `(d,)` |
| $X$ | $B\times d$，每行一个样本 | `X.shape == (B, d)` |
| $W,b$ | $m\times d$ 权重、$m$ 维偏置 | `nn.Linear(d, m)` 的参数布局 |
| $z=Wx+b$ | $m$ 维列向量 | `W @ x + b`，各操作数需匹配维度 |
| $Z=XW^\top+b$ | $B\times m$，偏置沿批维广播 | `X @ W.T + b`，`b.shape == (m,)` |
| $\ell_i,L$ | 单样本损失、批平均损失 | $L=B^{-1}\sum_i\ell_i$ |
| $\nabla_W L$ | 与 $W$ 同形状的梯度 | `W.grad.shape == W.shape` |
| $C,h$ | 类别数、隐藏层宽度 | 最后一层输出形状为 `(B, C)` |
| $H,\mathcal H$ | 隐藏激活矩阵、海森矩阵 | 前者存表示，后者存二阶偏导数 |
| $s(z),\sigma$ | sigmoid 函数、标准差 | 不再让一个符号同时表示两者 |
| $\eta$ | 正学习率 | 更新 $W\leftarrow W-\eta\nabla_W L$ |
| $\mathcal N(\mu,\sigma^2)$ | 均值 $\mu$、方差 $\sigma^2$ | 随机采样 API 的 `scale` 往往传标准差 $\sigma$ |

向量函数 $f:\mathbb R^d\to\mathbb R^m$ 的雅可比矩阵定义为 $J_{ij}=\partial f_i/\partial x_j$，形状 $m\times d$。若输出收到列梯度 $g$，输入收到 $J^\top g$。梯度形状的约定在各章保持一致。

**与位置编码讲义对接**：位置编码篇用 $W_Q\in\mathbb R^{d\times d_h}$ 和 $Q=XW_Q$；它等于本系列线性层权重的转置。先读形状即可换算，不应因为名字都叫 $W$ 就直接复制公式。

## 04 · 数值验证：怎样把公式与程序对起来

各章独立示例给出必要导入与数据，可在 CPU 上运行；示例中的输入和参数都会在当前代码块定义。NumPy 用于把每一项算清楚，PyTorch 用于核对自动求导；数值验证主要采用 `float64`，训练大模型时不必照搬这个精度。固定随机种子让例子可复现，浮点数用容差比较。

阅读时先在纸上算一个元素，再运行数组版本。比如线性层先算某个样本的某个输出，再看 `X @ W.T` 如何一次生成全部结果；求导先看一个权重如何影响一个损失，再看矩阵梯度如何收集各条路径。这样才能知道断言验证的是哪条推理，而不仅是看到“运行成功”。

配套脚本位于仓库 `foundations/`：`probability.py`、`linear_algebra.py`、`calculus.py`、`neural_network.py`。在仓库根目录建立环境后运行：

```sh
python -m venv .venv
.venv/bin/python -m pip install -r foundations/requirements.txt
.venv/bin/python foundations/probability.py
.venv/bin/python foundations/linear_algebra.py
.venv/bin/python foundations/calculus.py
.venv/bin/python foundations/neural_network.py
```

Windows 对应解释器路径是 `.venv/Scripts/python.exe`。断言验证的是本章等式或教学实验，不代表模型对真实数据的泛化能力。

函数图由数值采样生成，坐标轴、参数和图注一起阅读：正态曲线的纵轴是密度，损失图的纵轴是目标值，梯度箭头表示局部变化率。SVG 示意图负责展示形状和依赖关系，不用箭头长度暗示未测量的数值。

## 05 · 阅读方法：沿同一条计算链反复核对

每章从一个具体问题进入，在定义后展开推导，再用手算和代码核对。章末练习先显示题目，展开后才看到计算过程；建议先自行写出结果。阅读时反复检查以下三件事。

1. 这个量是样本统计、概率、密度，还是向量坐标？
2. 每个乘法的输入和输出形状是什么，平均究竟除以什么？
3. 公式成立需要什么条件，代码是否用了同样的条件？

例如 `np.var` 的 `ddof=0` 除以样本数，`ddof=1` 除以样本数减一；这一约定影响小批量统计。[NumPy 方差文档](https://numpy.org/doc/stable/reference/generated/numpy.var.html) 给出两种定义。本系列在线性层中统一采用 [PyTorch Linear](https://docs.pytorch.org/docs/stable/generated/torch.nn.Linear.html) 的权重布局，各章推导则直接由分量计算展开。
