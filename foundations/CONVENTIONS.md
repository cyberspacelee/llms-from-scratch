# 深度学习数学讲义规范

## 术语与记号

- 统一写“正态分布（高斯分布）”“前向传播”“反向传播”“偏导数”“梯度”“雅可比矩阵”“海森矩阵”。“均值”必须说明对象：样本均值是观测平均，总体均值是分布期望，不得笼统断言均值与期望不同。
- 首次出现写中文名称与英文：小批量（mini-batch）、批大小（batch size）、未归一化分数（logits）、独热编码（one-hot）、自动微分（automatic differentiation）。后文使用“小批量”“批大小”“未归一化分数”“独热标签”“自动微分”；API 和代码标识符保留原文。sigmoid、softmax、ReLU 为函数名称，首次解释其含义。
- sigmoid 统一记作 s(z)，标准差使用 σ；类别数统一 C；稳定 softmax 的最大分数记 a，不能借用输出维数 m；海森矩阵写作 \mathcal H，隐藏激活保留 H。正态分布用 μ 表总体均值，样本均值用横线记号。
- 标量小写，向量小写（默认列向量），矩阵大写；随机变量用大写 U、V，避免与批输入 X 混淆。向量不强制粗体，与原有 RoPE 讲义一致。
- 单样本 x ∈ R^d，批输入 X ∈ R^{B×d}，样本按行存放；W ∈ R^{m×d}，单样本 z=Wx+b，批量 Z=XW^top+b，b 沿批维广播。这与 torch.nn.Linear 的权重布局一致。
- 梯度与被求导参数形状相同；J_ij=∂f_i/∂x_j，反向传播为 J^top g。∇_W L 是矩阵，避免称作雅可比矩阵。
- 损失单样本 ℓ，批平均 L=(1/B)Σℓ_i；学习率 η。索引 i 为样本、j 为特征。ln 或 log 都指自然对数。
- 概率 P(U=u)，密度 p(u)，期望 E[U]，方差 Var(U)，标准差 σ；N(μ,σ²) 第二参数是方差。明确 ddof=0 与 ddof=1，以及 torch.var(correction=0)。
- 公式使用 $...$ 和独立行 $$...$$，转置 \top，逐元素乘 \odot；矩阵乘与逐元素乘必须区分。
